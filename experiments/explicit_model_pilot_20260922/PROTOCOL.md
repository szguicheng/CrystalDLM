# 首轮显式位点约束表示训练：冻结协议

用户请求：暂不继续探索新 tokenizer，使用现有 explicit site-constraint representation 训练模型，观察效果。

## 任务与范围

从头训练一个小型双向 Transformer，随机遮挡离散序列及连续数值，联合恢复。采样从固定长度的全 MASK 序列开始，迭代并行揭示高置信度位置，不使用真实目标长度、真实位点数、目标几何或候选答案库。

用户已指定仅给化学组成。条件为约分后的元素比例（118 维 log1p 整数配比），不提供空间群、晶胞原子数、位点数、序列长度或目标几何。空间群也是待生成信息；同组成存在多晶型，生成空间群不同不能直接判错。

比较：显式约束 SP1 与标准 Wyckoff 标签序列。使用同一标准化/理想化的常规晶胞和相同六位分数坐标精度。保留编码语法；训练目标中仍可能有精度、原点或残差字段，不将真实模板作为模型输入。标准化引入的改变单独记录，不把原始 CIF 无损性与模型生成能力混为一谈。

## 数据

固定官方 MP-20 commit e8e9add5df904284116af8a06c203555d908f290。
各 split 按 material_id SHA256 排序，预选 train 6000、val 512、test 512。两种编码都成功、公共长度上限内的材料才进入配对 cohort，所有失败/超长记录保留，不补抽替换。train/val/test ID 必须无交集。

连续浮点值作为带类型的数值槽位，采用共享的数值预测头，不把每个完整浮点字符串建立一个新类别。规则常数、操作符、元素、WP 标签和整数计数为离散 token。词表由训练数据及预先存在的晶体学符号域建立，测试集不参与拟合词表或数值归一化。

## 首轮预算

1 A100，4 CPU，32 GiB CPU 内存，通过同一 Slurm/tmux 会话执行。
初始模型：4 层、宽度 192、6 个 attention heads、FFN 768。固定 256 个目标位置，两种表示完全相同的参数构造与公共词表。
seed 17 与 29，每个模型每个 seed 4000 步，batch 32，AdamW。先做小批次过拟合与输入泄漏检查，再执行正式配对训练。
每 500 步在验证集检查，按预声明的验证恢复损失选择 checkpoint。测试集只在全部正式训练完成后评估。

## 指标

- 固定 50% 遮挡：masked-token CE/准确率、非固定语法内容准确率、数值误差；不把不同语法的 CE 直接当表示优劣。
- 从全 MASK 开始的 32 步生成：完整序列语法可解码率、有限正体积、无过近原子（0.5 Å 阈值）、约分后的目标组成符合率。
- 与目标结构的 StructureMatcher 匹配率、参考空间群一致率作为诊断项，承认同组成可以存在多个合理结构。另记录生成结构实际识别的空间群分布。
- 报告原始预测；不使用真实空间群投影晶格，也不使用真实模板修复生成结果。
- 保存样本、checkpoint、训练/验证曲线、实际参数量、时间/显存、数据覆盖及失败类型。

这是小规模表示可学习性/条件生成试验，不是材料稳定性、DFT 或大规模基础模型结果。是否优于 Wyckoff 对照需要看配对结果，不能根据 loss 下降预先下结论。
