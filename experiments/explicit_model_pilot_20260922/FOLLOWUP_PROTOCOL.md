# 仅组成条件生成：采样诊断续跑

继续用户已授权的显式位点约束模型试验。使用同一 SP1、同一组成条件与 Burgundy 计算节点；不在本机执行计算。

1. 冻结第一轮模型和正式测试结果。先用 seed 17 已训练权重，在验证集 SHA256 排序前 64 个材料上比较一次预测、原始置信度揭示、随机揭示、非 PAD 优先、随机重新遮挡。候选方案仅访问模型输出和输入组成，不访问目标长度、空间群、模板或坐标。
2. 主要选择指标为全部验证样本中的基础检查通过数，其次组成正确数、可解码数。token 准确率只用于诊断，不能在不同语法间直接比较。
3. 若仅改采样仍无法得到可用输出，优先依据诊断修正训练与推断的接口或监督方式，再做同预算配对续训；不把训练 loss 下降当作生成成功。
4. 有希望的方案在完整 512 验证集复核，冻结后才能重新评估已使用过的测试集。重新评估必须标为续跑、复用测试集，保留第一轮数字；需要正式泛化结论时另留新的未查看数据。
5. 保存完整失败预测、指标、配置和计算收据。此轮不进行稳定性或 DFT 验证，不更换 tokenizer。

在全验证集结果出齐前追加冻结：最终评估使用官方 test split 按 SHA256 排序的第 512:1024 行，和本轮此前 6,000/512/512 材料无 ID 交集。仍使用原先四个 checkpoint，不重训。采样器按两种表示、两个种子在完整验证集的基础通过数之和选择，再按组成正确数、解码数破同分；两种表示使用同一个采样器。选择与源码/权重 SHA256 写入 sampler_selection.json 后，才在新 512 个材料上比较原采样器和选中的采样器。新结果不参与下一轮选择。

事后诊断追加（已查看新测试集原始生成结果之后）：检查预测对称操作是否保持预测晶格度量及同元素位点集合。对称性不一致时，探索仅根据预测点群的群平均 M_new = mean(Rᵀ M_pred R) 来约束晶格。此后处理无目标结构输入、不改权重或原子分数坐标，复用新测试集且没有再取独立评估集，故只作为探索性后处理报告，不能替换冻结测试的原始结果。
