# 显式对称约束程序（实验候选）

这是针对“拆开 Wyckoff 字母，让空间规则本身可见”的新候选。把位点写成坐标表达式，把整体对称性写成少量生成操作，通过算术闭包恢复完整晶体。不使用 Wyckoff 字母、位点规则 ID、固定私有词典或逐原子邻接边列表。

例如 YbBPt₂ 的三个独立轨道可读为：

```text
Yb: x=1/2, y=1/2, z=5/6
B:  x=1/2, y=1/2, z=1/3
Pt: x=1-y, y=FREE(0.852342), z=5/6
```

这里前两组坐标固定，Pt 只有一个独立参数。整体生成操作展开后是 3 个 Yb、3 个 B、6 个 Pt。实际序列同时保存晶格、生成操作和输出精度，所以不能只拿这三行计算总长度。

## 语法与数学意义

- `x y z`：当前位点的局部坐标变量，或全局操作的输入坐标。
- `FREE value`：该坐标为独立自由参数，数值为 `value`。不同位点的同名变量相互独立。
- `ADD a b`、`NEG a`、`MUL a b`：普通加法、取负和乘法的前缀表达式，每个符号和数值分别计数。
- `1/2` 等数值：精确的有理常数，不是位点类别编号。
- `G` 后三个表达式：一个仿射对称生成操作的新 x/y/z。
- 元素符号后三个表达式：一个独立原子轨道代表的 x/y/z 位置族。
- `FAMILY n`：后面直接写一次三坐标约束模板，再列 n 个成员的元素和自由参数。模板用 `PARAM` 标出独立变量。规则在当前输入中完整可见，没有定义私有编号或查询外部规则表。
- 可选 `ORIGIN ox oy oz`：在有理对称参考系中表达坐标后，移回输入原点，三项平移均显式保存。
- `ROUND digits`：从精确骨架输出为原 CIF 的有限小数精度。
- `RESIDUALS n`：还不能由相同精度还原的原子修正，每条为展开后原子下标和三个分数坐标偏差，全部计入长度。修正不隐含为精确空间群对称的一部分。

编码器识别近似空间群，取固定位点的仿射操作方程 `(R-I)q=n-t`，对有理方程作行最简化，分离独立变量与从属坐标。全局生成元通过有限群闭包选择，逐操作比较闭包是否与识别的完整操作集一致。

解码器不调用 spglib 识别空间群，不查询 Wyckoff 或空间群数据库。它解析数学表达式，从生成元闭包恢复所有操作，求代表坐标、展开等价原子、按精度舍入并应用显式修正。当前 Python 模块为方便复用同时导入编码依赖，但解码路径不调用这些识别/查表接口，扩大审计时会禁用这些接口检验。

## 命令

```bash
python program_codec.py encode input.cif encoded.sym
python program_codec.py decode encoded.sym decoded.cif
```

依赖沿用 Burgundy matgl 环境中的 numpy、scipy、sympy、spglib 和 pymatgen。科学计算在 Slurm 计算节点中执行。

## 第一关实际结果

原来十个材料已经完成独立进程 decoder 的 CIF 往返检查，全部通过。KrF₂ 是 59 → 47，YbBPt₂ 是 122 → 49，其余案例的完整程序也短于原 CIF。YbBPt₂ 保留 #180 的符号规则，没有沿用旧方案的 #3 降对称。AlIn(CuS₂)₂ 有两个原子需数值残差，共额外 8 个字段，已计入其 56 个序列单元。

这些长度按每个数学原语、数值和格式标记计一个单位；完整表达式不会算成一个词。连续数值尚未量化，不是通用语言模型 BPE 数量。CIF 计数含其语法元数据，扩大审计同时列出纯结构字段基线。

## 扩大验证

最终版本已通过：512/512 个固定真实 CIF，530/530 个标准 Hall 设置的生成元闭包，1731/1731 个默认设置 Wyckoff 位置族（每种 3 个自由参数实例，共 5193 次），以及 32 个新材料的原始/平移原点/换基底共 96 次信息保留检查。

512 个真实 CIF 中 509 个完整程序不长于 CIF。长度比中位数为 0.5638，95 分位数为 0.8821，最大值 1.0882。总长度 31,239 对 56,248，减少约 44.5%。实际数据中 87 个结构需要显式残差，所有残差字段都已计入。数据、范围、长尾与逐例结果见 RESULTS.md。

## 尚未证明

当前没有验证实际 LLM 的学习/生成收益，也没有证明不同原点、基底、原子排序一定得到相同 token 序列；验证的是解码后的结构信息一致。覆盖测试不等于任意 CIF 的生产级支持，尤其无序/部分占位、磁性、任意超胞和实验元数据不在当前范围。

连续数值还未量化为有限离散词表。`FREE` 和残差数值目前是连续槽位，而非某个现成 LLM 的 BPE token。下一步模型实验需要明确采用连续预测头还是数值分词，以及同模型的标签表示对照。

仿射约束、Wyckoff 坐标模板、自由参数和群生成元均有明确先例。潜在区别是无 Wyckoff 标签、无需查表的统一数学程序接口。详见 `research/notes/explicit_symmetry_constraints_prior_art_20260917.md` 的原文审计，不把检索未发现当作新颖性证明。
