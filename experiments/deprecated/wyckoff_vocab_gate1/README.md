# 第一关：单元素 Wyckoff 占位分配词表规模

固定 PyXtal 1.1.4 的 230 个空间群默认表格，扫描一个元素在表格晶胞内的原子数 N=1…40。只在 Burgundy 的 Slurm CPU 作业内计算，不训练模型、不调用 GPU、不生成几何、不做材料稳定性计算。

## 计数对象

每个候选是整数向量 `(n_w)`：它记录同一元素在各个有标签的 Wyckoff 位置上占据多少个独立 orbit。令该位置重数为 `mu_w`。

- 零自由度位置：`n_w ∈ {0,1}`。
- 有自由度位置：`n_w ∈ {0,1,…}`，实际由总原子数限制。
- 满足 `sum(mu_w * n_w) = N`。
- 同一 Wyckoff 位置的重复 orbit 不排列计数。

精确生成函数为：

`F_G(x) = product_fixed(1+x^mu_w) * product_free(1-x^mu_w)^(-1)`。

动态规划计算 `[x^N] F_G(x)`，使用 Python 任意精度整数。没有枚举截断、快速模式或候选数量上限。额外统计合并相同重数后有多少种重数分拆，作为分层编码的规模参照。

## 数据与完整性

`input/provenance.json` 记录官方 PyPI wheel 下载地址、版本、wheel SHA-256 和抽取文件 SHA-256。仅读取 wheel 中的晶体学数据文件，不安装整个 PyXtal 及其依赖。

通过 Wyckoff 表中第一个仿射坐标映射的线性系数矩阵秩确定自由度。表达式用受限 AST 算术解析，系数用有理数表示。核对 230 个空间群、1731 个位置。

## 独立校验

- 对全部 230 个空间群的 N=1…6 做独立递归穷举，与动态规划结果逐项比较；同时核对去掉位点标签后的重数分拆计数。
- 全部 1731 个坐标映射的有理数矩阵秩，与 NumPy 数值秩交叉核对。
- 用 P1、P-1 的闭式生成函数，以及空间群 225 的小计数检查边界。

## 解释边界

1. N 是 **PyXtal 默认表格晶胞中的单元素原子数**，不是化学式最简比例，也不是 MP-20 的原胞总原子数。菱方群使用该表默认的六方设置。
2. 统计的是有标签占位描述，尚未对等价原点/晶胞选择取商；因此它是该直接编码下的准确规模，不是物理不等价结构数量。
3. 单元素计数可行不代表多个元素之间没有固定位置冲突。
4. 不含自由坐标、晶格、碰撞检查和能量；合法计数不等于物理有效或稳定晶体。
5. 所有 `(G,N)` 上下文等权，只能判断表示的组合规模；真实材料的分布与收益属于第二关。
6. 重数分拆计数较小不代表整个分层 tokenizer 就有同样小的总词表：具体 Wyckoff 身份仍需编码。
