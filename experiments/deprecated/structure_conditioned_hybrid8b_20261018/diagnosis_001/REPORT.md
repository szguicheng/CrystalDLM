# Hybrid8B 首轮失败诊断

日期：2026-10-18。范围：复核现有 700 次生成、训练/采样代码和冻结检查点的小样本推理；未重训、未修复正式输出、未改变正式评分。

## 结论

目前定位到的主要瓶颈是：晶体去噪器能利用真实片段补全序列，但尚不能可靠地从全 MASK 生成自洽的完整 Wyckoff 文本。当前采样又会永久保留较早采出的 token，给格式错误的传播提供了条件。结束位置与正文格式同时失败，单独修 END/PAD 不足以解决本轮问题。

这是对当前检查点和配方的判断；尚未通过训练或采样消融证明哪一项修改能恢复生成质量。

## 已确认的证据

1. 正式生成 700/700 成功从文字切到晶体；0/700 严格有效。292 条失败于 END/PAD 边界，另外 408 条边界通过但正文检查失败。GRACE 实际物理计算为 0 次，因此此次失败发生在性质评价之前。
2. 使用同一冻结检查点、正确参考文字、固定 seed=42 抽取的 8 条训练样本和 8 条验证样本，做四档遮盖率的去噪检查。只统计被遮盖的正文 token，不把 PAD 算进准确率：

| 遮盖率 | 训练样本正文恢复准确率 | 验证样本正文恢复准确率 |
|---|---:|---:|
| 25% | 88.12% | 85.75% |
| 50% | 86.90% | 83.03% |
| 75% | 84.23% | 81.69% |
| 100% | 42.59% | 35.03% |

全遮盖时，验证样本 PAD 恢复准确率仍有 99.43%，而真实 END 位置的 top-1 恢复为 0/8。整体 token 准确率容易被大量简单 PAD 掩盖，必须分开观察。训练原本已将 PAD 权重降至 0.1，所以不能说训练完全由 PAD 主导。

全遮盖准确率衡量的是与某一参考序列一致，不是生成有效率：同一条件允许多个合理结构。这组数字说明任务难度和可用信息存在显著差异，不能把每个参考 token 不匹配都判作结构错误。

3. 对预先选定的前 4 条验证样本，直接使用正确的参考文字，运行原样的 32 步全 MASK 采样，仍得到 0/4 有效结构：2 条边界失败、2 条正文解析失败。该小样本说明文字生成错误不是失败的必要条件；它不是新的正式 benchmark。
4. 训练时可见的晶体片段来自真实结构；推理时可见片段来自模型先前的预测。采样每步以 1/k 概率随机释放位置，已经释放的位置后续不再修改。早期猜错的分隔符、长度或字段因此无法在本次采样中纠正。这是当前算法的行为，不等于实现错误；其影响大小还需要控制变量实验。
5. 匹配纯 AR 同样使用 Qwen3-8B、7272 条训练材料、一轮 LoRA 微调，但得到 95/700 有效结构。由此不支持把此次全军覆没直接解释为“8B 放不下”或“这批数据完全不可用”。两种生成机制并不保证在相同训练量下具有相同学习难度。
6. 独立代码核查在已审路径中没有发现训练/采样的确定性错位：K=544、同位置预测、晶体块双向注意力和时间步嵌入一致。该结论不等于排除了所有软件问题。
7. 流程存在明确缺口：`evaluation_preflight_001/shard-00-of-01/summary.json` 已显示 0/7 有效，但 `launch_pipeline.sh` 只依赖命令退出码，未根据生成质量拦截，随后继续跑了 700 次。前面的梯度、检查点恢复和前缀缓存校验通过，也不能证明晶体能有效生成。这是没有及时发现并停止批量失败的原因，不是模型生成失败本身的原因。

## 归因强弱

- **已经定位：** 完整晶体生成的序列一致性没有学好；结束边界和正文均有问题；不是 ehull 评分造成失败。
- **优先验证的解释：** 从因果语言模型转为同位置双向去噪，需要更多适配；当前一轮训练中全 MASK 时刻的抽样概率只有 1/32，训练主要面对含真实片段的补全任务；推理早期预测错误又不可撤销。
- **尚未证明：** 多训几轮、增加高遮盖训练、换采样策略或缩短块长度，哪一种足够解决问题。全 MASK 下参考恢复较低本身不能证明模型不会生成其他有效结构。

## 建议的下一步

先用固定的小规模生成集做受控比较，不重复直接跑 700 次。保留当前检查点作为对照，分别验证高遮盖/全遮盖适配，以及允许重新考虑早期预测的采样；每次只改变一项。先以原始严格有效率和 END/PAD、正文错误率判断是否改善，再进入完整性质评估。批量评估前应检查小样本实际生成质量，不能仅检查退出码。
