## 表示定义与边界

头部保留晶格、不等价原子的元素/WP 标签/连续分数坐标，以及当前设置下的完整空间群操作表。每条离散边记录为：

`(source_orbit, target_orbit, operation_id, image_x, image_y, image_z)`。

其语义是从源轨道代表连接到目标轨道代表经指定空间群操作及整数晶格平移后的像。操作加平移来自 CIF bond symmetry code 的既有概念；按完整空间群把等价边合并为一条边轨道记录。无向边的两种方向与源位点的 stabilizer 等价性在编码时处理。

这里只用 **4.5 Å 截断半径近邻图** 测试离散周期连接，不声称识别了化学键。解码器接收压缩表示，独立展开原子与边，原始完整坐标数组和完整邻接表不作为解码输入。

这不是纯离散、无坐标的 SLICES 式几何重建器：连续 ASU 坐标仍在头部。坐标往返对象是 symprec=0.1 Å、angle tolerance=5° 下经过 idealization 的标准常规晶胞；不是未经对称化的原始 DFT 坐标。

## 已执行检查

- 每个空间群操作能唯一映射同元素原子，且映射为置换。
- 原始周期边集在所用空间群作用下闭合。
- 不同边轨道不会映射成同一离散标签。
- 压缩表示经过 JSON 序列化后仍能独立解码。
- 展开后原子一一匹配，周期边集完全相同；坐标误差小于 1e-6（分数坐标）。
- 强基线：对同一 idealized 晶体取原胞，使用同样半径重新构图；逐结构检查常规/原胞原子数与边数的 centering 比例一致。

## 512 个训练结构的结果

512 / 512 成功，失败 0。以下是所有结构的记录总数：

| 表示 | 原子/节点记录 | 无向周期边/边轨道记录 |
|---|---:|---:|
| 常规晶胞图 | 9682 | 102992 |
| 原胞图（更强基线） | 5219 | 57407 |
| 空间群轨道表示 | 2390 | 15405 |

相对原胞图，节点记录减少约 54.2%，边记录减少约 73.2%。这说明减少不仅来自把常规晶胞换成原胞。

这些数字是**节点/边记录数量**，不是最终语言模型 token 数、序列化字节压缩率、显存节省或训练提速。边记录包含不同字段；头部目前显式保存操作表，后续共享字典成本也必须计入。P1 等低对称结构不能期待同样的减少。

## 已有工作边界

SLICES 已有平移标记的周期商图，SLICES-PLUS 已附加空间群操作，SGEquiDiff 已有 ASU/Wyckoff 代表与完整空间群展开。潜在差异只能落在**可逆的离散边轨道表示，以及模型是否直接在这些记录上计算或去噪**。

SGEquiDiff 全文及附录 A.4.2 的核查显示，其 score GNN 仍在完整常规晶胞图上计算；未报告这里的 CIF-like edge-orbit token。详见 `research/notes/sgequidiff_graph_overlap.md`。这是有限范围的先例核查，不是全球新颖性证明；WyckoffAUGen 的完整附录仍有访问限制。

## 下一步：模型用途验证

先验证图去噪骨干能否直接消费压缩记录，而不在每次 forward 展开整个图。

1. 对照使用同一晶体的原胞图、相同权重、相同特征与相同扰动；不能只对比更大的常规晶胞图。
2. 对标量径向 message passing，按每个源轨道的邻接重数加权，检查完整图与轨道图的前向输出和梯度。轨道平均须按原子重数加权。
3. 测量实际 GPU 峰值内存与耗时，分别报告一次性编码成本、前向、反向；记录数减少不能代替这些测量。
4. 若要用于坐标扩散，须进一步保留操作对应的方向变换，并检查受 WP 约束的对称扰动下，向量输出与完整图对应一致；标量网络通过不代表坐标去噪已经通过。

只有完成这些检查后才决定模型训练与最终 tokenizer 设计。目前结论是：**图编解码和相对原胞的记录减少已验证，模型收益未验证。**
