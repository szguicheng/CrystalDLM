# 首组模型对照：按条件构造的组合式占位 token

这是开发阶段的 tokenizer 诊断，不是完整晶体生成或材料稳定性实验。

## 候选表示

给定常规晶胞组成与空间群 G，每种元素对应一个未知的 Wyckoff 占位分配。候选词表仅由 `(G,N_e)` 和标准 Wyckoff 表决定，不读取目标结构、训练频率或测试标签。候选用各 Wyckoff 身份与 orbit 占据次数构造向量，不为全部组合学习独立 embedding。

第一关排除了无界平坦词表。此处先采用预先选定的 `candidate_cap=256` 进行有界诊断：单元素候选数超过 256 的上下文**整体不进入本组模型实验**，不截断候选列表。保留后的每个上下文都完整枚举并验证总数；任何推广为全数据模型都需要补充分层或回退表示。

真实数据覆盖：train 26,086/27,106，val 8,668/9,037，test 8,730/9,037。预处理另有 train/val/test 30/10/9 个重数一致性失败样本；所有对照同样排除并记录。源 CSV 实际合计45,229条，不能沿用README中45,231条来报告本次样本量。

## 两个同容量对照

共同输入是元素、单元素原子数、空间群，以及未被mask的元素占位。Transformer 没有元素槽位位置编码。训练随机mask一部分或全部元素占位，验证时所有占位未知，只给G与组成。

每个候选的基础向量由各WP的身份、重数、自由度、占据次数嵌入相乘并求和得到 `s(profile)`。

- **factorized**：`score = MLP(query) · s(profile)`。候选能量对WP占据贡献可加，是逐位点计数打分的强基线。
- **compositional**：`score = query · MLP(s(profile))`。非线性发生在完整占位候选上，允许对WP共占据模式建模。

两者具有相同的模型参数数量、输入条件、基础嵌入、Transformer、MLP大小、候选集合和优化器。相同种子提供相同初始化及数据/掩码抽样。两者都在**同样完整且满足单元素计数约束的候选集合**上归一化；因此组合式方法不能仅凭计数合法性取胜。

共同可见状态编码使用相同结构化投影。隐藏目标profile ID的替换不应改变全mask预测，GPU smoke 中显式检查此项。

## 初始预算与指标

- 3层、128维、4头 Transformer；AdamW lr=3e-4，batch=64，seed=17，2,000步，每500步验证。
- 验证集按 material_id 哈希固定选择2,048条；用于开发，不在此阶段评估测试性能。
- 保存最佳验证NLL检查点和逐结构预测，报告参数量、GPU型号、耗时和显存。
- 主诊断指标：非平凡候选下的单元素准确率、平均profile NLL、带标签的完整protostructure exact-match。
- 辅助指标：跨元素固定位置冲突、训练未见正例profile上的准确率。

## 不能据此声称

- profile数量为1的容易情形会抬高总体准确率，因此单独报告 ambiguous-element accuracy。
- 标准化后的带标签exact-match没有对所有原点等价关系取商，不能直接当物理结构匹配率。
- 独立元素argmax尚未做全局冲突修复；后续强对照应给两者相同的联合合法解码。
- 此阶段没有多步生成、多种子、完整测试集和几何阶段。单种子开发胜出不足以完成研究目标。
- 这主要验证输出token组织与候选嵌入的作用；不能只因Transformer或候选score网络发生变化就宣称发明了新晶体学概念。
