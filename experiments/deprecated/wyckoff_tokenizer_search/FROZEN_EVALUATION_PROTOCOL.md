# 冻结复核与最终测试协议

当前候选为 Wyckoff 计数块：以 RLE 计数记录为基础，只在同 SG、同元素内部合并最多 3 个不同 WP 的记录，182 条训练频率规则，RLE 回退。该版本不在测试模型数据上做词表、阈值或超参数选择。

## 冻结项

- 数据：`count_merge_candidates/data.pt`，SHA-256 `ae8d9046e4e58e03a0f2cb0f2eba27e0da2f3973bcbac1a5e6c4d1616d8ef28b`。
- 模型源：`direct_words.py`，SHA-256 `8ec754e67884714c160def31714e42a226254e2d6a3555747a0bbd96751c8590`。
- 两个变体：RLE 与 rlemerge；相同 499,776 参数、位置参数容量 17，实际槽位 9 与 6。
- 每种变体每个种子 10,000 步，batch32，固定种子 17/29/43；其余超参沿用已记录协议。
- 每 1,000 步在固定 2,048 条验证结构上评估，按平均 profile NLL 选择检查点。
- 输入只给 SG、组成及去噪训练时可见的词；评估全遮盖，不输入真实词数或正确 profile。
- 相同 cap256 完整候选集合与固定 WP 排他 MAP 读出。

## 顺序

1. 所有六次训练必须完成；核查数据、代码、参数和预算一致。
2. 重新加载全部检查点评估原固定验证集，并核对与训练收据一致，再汇总多种子稳定性。
3. 若开发信号没有反转，执行一次冻结测试：全部 8,730 条共同保留测试结构。
4. 测试后不根据结果改此版本的词表、超参、预算或检查点选择规则；若失败，明确保留失败结果并重新提出新的开发假设。

## 报告与解释

- 每个训练种子的整结构匹配率、平均 profile NLL、逐结构预测均保留。
- 报告三种子均值、每种子差异，并对成对种子与结构做层级 bootstrap。只有三个初始化，不能把这当作全面覆盖训练随机性的精密推断。
- NLL 是完整单元素候选集合上归一化后的 profile NLL；不是最终固定位置联合分布的完整晶体 log likelihood。
- 峰值 GPU allocation 与耗时使用训练收据。槽位变少或显存下降不自动等于吞吐提升。
- 匹配率区间跨零时不声称匹配率提升；同样不能把无显著差异解释为严格非劣。
- 与只用训练集拟合的条件频率基线对照，避免以明显弱模型的变化作充分推荐依据。

目的在于确认 tokenizer 是否有可复现的条件建模/资源作用及具体文献差异。完整无枚举扩散采样、几何、原点等价取商和物理稳定性仍是另一个阶段，不能从本实验推导。
