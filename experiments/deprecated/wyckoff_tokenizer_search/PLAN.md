# Tokenizer 搜索与验证计划

目标：找到对晶体模型有实际作用、并相对已核查文献存在具体方法差异的 tokenizer。只采用基础晶体学概念的组合和编码，不继续母相/畸变模式方向。所有预处理、计数、训练及科学评估在 Burgundy Slurm 计算节点运行；登录节点只做下载、传输和提交。

## 当前证据与未决问题

第一关已完成（`../wyckoff_vocab_gate1/RESULTS.md`）：逐元素完整占位的无截断词表存在极长尾，不能建立全覆盖平坦词表。该结论还未按真实材料频率加权，也没有模型实验。

需要回答：

1. 在真实 MP-20 中，高候选数上下文的占比，以及每元素多 orbit 分配的出现频率。
2. 结构化、可组合或分层候选编码是否比逐 orbit/逐占据变量编码更好学。
3. 与已有 WyFormer composition/multiplicity 配置、WyckoffDiff、约束 Wyckoff 分配工作的重叠边界。

## 数据阶段

- 固定 WyFormer 官方仓库 commit `e8e9add5df904284116af8a06c203555d908f290` 的 MP-20 train/val/test CSV。
- 保留原始划分、文件 SHA-256、material_id，任何读取或标准化失败单独报告。
- 使用 pymatgen 读取 CIF、spglib 以 `symprec=0.1 Å, angle_tolerance=5°` 标准化到默认常规设置。记录 Hall 编号/choice，检查每个 orbit 的实际元素数与 PyXtal 表格重数一致。
- 固定 PyXtal 1.1.4 数据表。不将化学式最简比例、原胞计数和常规晶胞计数混为一谈。
- 先对训练集 1000 条做 smoke，验证数据链路；通过后用 Slurm array 分别处理三份完整划分。

## 模型比较原则

- 先用“给定组成和空间群的离散占位生成/补全”作为 tokenizer 诊断任务；这是实验任务，不预设最终产品只做组成条件。
- 相同数据、条件信息、骨干容量、训练预算和评估协议。不能把真实 orbit 数、测试集词频或测试答案注入某一个候选。
- 训练集用于学习词表/频率；验证集用于选择方案；最终测试评估保留到候选与超参确定之后。初期可以分析 test 的纯表示覆盖/数据完整性，但不得用其模型结果选超参。
- 构造保证的计数合法性只作为协议检查；模型作用需通过结构预测、去噪恢复、采样多样性、条件任务准确率或实际计算成本得到支持。
- 报告带相同合法解码/修复约束的基线；不能只与明显缺少约束的弱基线比较。
- 先小模型/单种子开发，再多种子核实有效候选；受数据划分影响的结论需要明确范围。

## 完成要求

必须交付明确且可逆到目标表示层级的 tokenizer、可复现代码/数据版本、同条件模型对照结果、失败案例和局限，以及一手文献支持的创新边界。仅有计数、表示覆盖、训练进程启动或口头设计，均不能认定目标完成。
