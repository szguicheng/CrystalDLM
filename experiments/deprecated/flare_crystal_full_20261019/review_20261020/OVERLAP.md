# AR 与 FLARE 生成材料重合复核

2026-10-20。使用保存的原始有效CIF及GRACE回执中的弛豫结构进行CPU比较，没有重新生成、训练或计算性质。

沿用正式评分的`StructureMatcher(ltol=0.3, stol=0.5, angle_tol=10, primitive_cell=True, scale=True, attempt_supercell=False)`，先按约化化学式分组，再匹配结构。这里的“相同”指此评估容差下匹配，不是文本或原子坐标逐字相等。固定方法的`angle_tol=10`与空间群识别的`angle_tolerance=5`是不同设置。

最终候选：AR独有12种，FLARE独有11种，共同13种，占AR的52.0%、FLARE的54.2%。所有阶段的跨组匹配均为一对一；AR优先和FLARE优先的贪心合并唯一数相同。两组各700条晶体原始字符串内部均唯一，跨组完全相同字符串为0；字符串不同仍可能是同一材料。

共同13种的约化化学式：SrPrMg6、Cd3Sn、PrCd3、CeInAu2、Zr3Cd、Dy3Mg、YbTl3、TbZn3、LiHg3、Dy3Hg、Dy3In、CaBi3、LiMg3。具体尝试ID和两侧ehull见`structure-overlap.json`。

两组最终候选有14种相同约化化学式，但只有13对结构匹配。剩余PmMgPd在两侧均属SG194，却未通过同一StructureMatcher匹配。因此不能仅按化学式或空间群认定材料相同。

## 为什么最终数量接近

本轮筛选漏斗：

- AR：169有效 → 26低ehull且收敛 → 26满足弛豫后SG → 25新颖唯一。
- FLARE：121有效 → 26低ehull且收敛 → 25满足弛豫后SG → 24新颖唯一。

两组都有26个低ehull候选；在各自有效候选中对应15.4%与21.5%。这是观察到的筛选比例，不能据此单独证明FLARE的性质控制更强。AR和FLARE都因匹配训练库而去掉了`sg-194/079`的RbMnBr3；FLARE还在先行SG筛选中去掉`sg-015/065`的CaMg2（弛豫后SG74而非请求15）。最终一步没有额外同组重复扣除。

最终合格结果都集中于SG194：AR18/25，FLARE20/24。两组共享源AR检查点、数据与请求，700个配对尝试seed也相同；全部13对共同达标结构都出现在相同请求/attempt/seed位置。这支持“二者探索了相近的材料区域”的解释，但不是独立证明某一个训练因素导致重合。700对文字lead中只有25对逐字相同，共同13对最终结构的lead均不是逐字相同。

因此确有约一半最终候选重合；最终数量接近同时来自相似的低ehull候选数与相似的后续筛选损失，并非每组反复生成大量相同结构后被去重到相似数量。

证据：`compare_structures.py`、`structure-overlap.json`、`structure-overlap.log`和原1400份生成及评分回执。未作DFT重判或不同随机种子的重复实验。
