# 边轨道 tokenizer：10 个 CIF 往返实验

一个不训练神经网络的最小 encoder/decoder。复用既有位点稳定子、边轨道合并和展开算法，补充实际 CIF 读写。

```bash
python cif_codec.py encode input.cif encoded.json
python cif_codec.py decode encoded.json decoded.cif
```

编码保存全局空间群/操作表、位点约束、边轨道，以及独立的连续几何载荷（晶格、自由坐标）。解码器只读取 JSON，不访问原始 CIF。只有离散 prototype 时不能唯一恢复晶格和自由坐标。

依赖 NumPy、spglib、pymatgen。往返检查另外使用 SciPy。实际验证版本与 Slurm 作业写入 `results/summary.json`。

## 范围

- 不标准化晶胞，不理想化坐标，不把原胞换为常规晶胞。
- 输入限定为有序、满占位结构。检查元素、原子数、晶格、周期坐标以及 4.5 Å 半径近邻图。
- 不保证保留 CIF 注释、位点名称、文献字段、实验热参数、磁矩等元数据。输出使用 P1 列表完整列出所有原子，并不意味着结构失去原有对称性。
- 坐标允许误差为 `1e-6 Å`，晶格矩阵分量允许误差为 `1e-8 Å`。默认 spglib 对称识别容差为 `1e-7 Å`，可用 `--symprec` 修改。数值误差逐例记录，不声称文件字节完全可逆。
- 核心 codec 将输入近似坐标约束到识别出的对称位置族。若误差或映射超过内部/外部容差，测试失败，不以悄悄理想化或替换样本掩盖。
- 沿用的研究核心要求操作的分数平移可在 `1e-8` 容差内表示为分母不超过 48 的有理数。任意非标准原点、无序占位和磁性结构不属于本轮已验证范围。
- 边是距离截断的近邻关系，不自动视为化学键。解码几何只需要位点和几何载荷，边记录另外恢复邻接图。

## 十个样本与验证

来源为 WyFormer 官方仓库 MP-20 训练集，固定 commit `e8e9add5df904284116af8a06c203555d908f290`。文件 SHA256 为 `133bab58dba02d316f9f91174839f17802dce648be4e8659d1a42b32b97fa01d`。

按材料 ID 的 SHA256 排序，从每个尚未出现的数据集空间群取首个材料，直到 10 个。选择依据来自源数据元信息，不依据转换是否成功。所有失败保留，绝不替换。严格坐标容差下重新识别的空间群可能低于数据集标记，两者分别记录。

```bash
python test_roundtrip.py --csv /path/to/train.csv --out results
```

该完整审计要求运行在 Slurm 计算节点。单文件 encode/decode 命令没有 Slurm 限制。

每例输出：`input.cif`、`encoded.json`、`prototype.json`、`geometry.json`、`decoded.cif`、`reencoded.json`、`full_graph.json`。独立解码进程只接收 `encoded.json`。重新读取输出 CIF，再编码、解码并比对。

压缩统计分开报告原子/边记录数、编码 JSON 大小、原始 CIF 大小、同信息全展开图 JSON 大小及各自 gzip 大小。记录数不等同于模型 token 数。全展开图和编码包含相同的结构+近邻关系，而普通结构 JSON/CIF 没有同等边信息。当前内联操作表的开销计入实际文件大小。

检查还会给同一个 prototype 改用另一组允许的自由参数，验证抽象连接保持而几何可以变化。即使所有位点固定，改变晶格长度仍能得到另一个结构，因此离散部分本身不能唯一表示材料的完整几何。

## 本轮结论

最终在 `symprec=1e-7 Å` 下 10/10 通过。初步使用 `1e-5 Å` 时只有 5/10 通过，详见结果报告与 `evidence/`。收紧识别容差后，5 个样本保留的对称群低于数据集标签，一个为 P1。这里反映输入数值的严格对称性，并不证明材料实际物理空间群发生变化。

90 个原子对应 52 条位点记录，888 条无向周期边对应 336 条边记录。自包含 JSON 合计 28,151 字节，大于原 CIF 的 11,293 字节，也大于同信息的全展开图 JSON（15,476 字节）。表示记录数减少，当前序列化文件总体不压缩。
