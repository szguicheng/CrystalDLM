# NatureCry：Kimi 自然语言编解码的冻结 100-case 验证

日期：2026-10-02。用户授权继续验证，使用已指定的 SciencePal / `tokenhub/kimi-k3`。
范围仅为主实验：LLM 自由空间描述 → 隔离 LLM 语义解码 → 恢复原晶体；不执行等义改写、参数修改、模型训练或混合生成。

## 样本与硬要求

逐字沿用 `../naturecry_roundtrip_20261001/run_001/selection.json` 的全部 100 个 case：两个公开生成样例和 98 个 MP-20 记录。
每个原始 CIF 均核验冻结 SHA256，失败不剔除、不换样本。
保持输入晶胞，原子数和元素计数完全相同；同元素周期性一一匹配的最大坐标误差 `< 1e-6 Å`，晶格矩阵分量误差 `< 1e-8 Å`。
验证写出并重新解析的 CIF，不用语义评分或理想化后的新结构替代原结构。

## 相对两个案例试点的接口扩展

100 个输入中有 71 个需要输入/标准晶胞的坐标转换，17 个需要小的逐原子精度修正，不能只处理无转换、无修正的简单案例。
事实包与结构计划因此包含原始晶格/组成、标准 Hall 轨道、`q_standard = P q_input + s`、必要的舍入精度和精度修正。
修正通过“元素＋修正前的输入分数坐标”定位原子，避免依赖模型轨道排序或代表点选择造成的内部原子编号变化。
相关数值必须出现在 LLM 的自然语言正文中；decoder 没有事实包、源 CIF 或隐藏 sidecar。

空间群描述对称性骨架；精度修正保存原始近似对称几何。最终依然与原始输入比较，不声称输入严格理想对称。
Hall 符号通过公共表确定索引，同时校验空间群号。查表时结合空间群号区分可能因空格规范化而混淆的符号（例如 `P 32` 与 `P 3 2`）。

发起 LLM 请求前，几何内核已用真实数值对全部 100 个输入做 oracle 检查，证明数值接口可以还原它们。oracle 构造计划不提供给 decoder；只为隔离程序错误。

## 调用与记录

encoder 与 decoder 都使用 `tokenhub/kimi-k3` 的 OpenAI Chat Completions 接口。
encoder 温度 0.4，decoder 温度 0；每次最大输出预算 8192 tokens；正文自由组织，禁止固定模板、CIF/JSON 附录和材料 ID。
每个 case 一次 encoder 调用，若得到完整描述再做一次无共享对话历史的 decoder 调用，最多 200 次请求。
使用四个并行 case worker，每个 case 内编码与解码顺序执行，无自动重试或补写。
密钥通过运行环境或无回显输入读入，不写入代码和结果。

保存原 CIF、encoder 事实、两次请求、原始响应、模型/使用量 receipt、自由描述、结构计划、输出 CIF、失败阶段与逐例判定。
源代码和两段提示词在运行目录冻结。公开晶体学表及原 Wyckoff 几何后端作为共同程序依赖。

## 结果解释

主通过率始终以冻结的 100 个 case 为分母。
API/连接/输出截断问题单列；描述遗漏、语义解析、几何执行和原结构不匹配也按阶段报告。
同一模型的隔离请求不等于跨模型泛化；结果只描述该模型、提示和固定 cohort 下的首次恢复表现。
辅助表示性能实验留待后续。本轮完成 100-case 主实验后结束。
