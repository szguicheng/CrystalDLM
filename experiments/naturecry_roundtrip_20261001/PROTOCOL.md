# NatureCry v0.1：100-case 编解码协议

日期：2026-10-01。范围仅为受控自然语言编解码，不训练模型，不实现混合生成流程。

## 编码方式

采用英文固定句式，写明输入晶格、元素组成、原子数、空间群/Hall 设定，以及每个独立 Wyckoff 轨道的元素、多重性、代表坐标约束和自由参数。
decoder 校验这些字段的一致性，将自然语言解析为已有的可逆 Wyckoff 表示，并通过固定公共晶体学表恢复结构。
原版 Wyckoff 表与几何后端复用 `../explicit_full_mp20_20260923/codec/wyckoff_baseline.py`。

统一对称识别容差为 `1e-3 Å`，沿用该后端默认值。
为恢复原始输入几何，自然语言也包含必要的原胞/常规胞坐标转换、原点移动、输入数值精度和逐原子精度修正。
修正内容属于编码正文；不通过源 CIF、隐藏 JSON 或材料 ID 查表补齐结构。
上述额外内容的比例和长度全部计入报告。空间群描述的是对称性骨架，精度修正保留原始有限精度/近似对称的数值，不能将修正后的输入宣称为数学上严格理想化的对称结构。

数值使用 Python 浮点往返字符串，不使用 PLaID 的两位/三位小数截断。
本版保留结构数据，不保留 CIF 注释、原子标签、热参数等实验元数据；范围为有序、满占位晶体。
本版句式固定，尚不支持任意同义改写或自由文本解析。

## 样本冻结

共 100 个 case：

1. Tb₈Mg₄：本地 `research/plaid_20260930/released_0_decoded.cif`，作者公开生成样例。
2. Li₈V₄Ni₄O₁₆：PLaID 旗舰结果 CSV 零起算第 1400 条记录的 `cif`，作者公开生成样例。
3. 98 个 MP-20 训练集真实记录：从官方 PLaID 的 `data/basic/train.csv` 读取，按材料 ID 的 SHA256 排序，对每个尚未出现的数据集空间群取首个样本，直到 98 个。

训练 CSV SHA256 必须为 `133bab58dba02d316f9f91174839f17802dce648be4e8659d1a42b32b97fa01d`，与之前 tokenizer 往返测试的数据版本相同。
该 cohort 为强调空间群覆盖的确定性样本，不是对训练分布的随机无偏估计。
在编码前写出所有 case 的来源、原始 CIF SHA256 和选择规则。失败不剔除、不替换，不针对不同 case 调整识别容差。

## 测试路径

输入 CIF → NatureCry 文本 → 独立 decoder 子进程 → CIF → 重新解析 → 再次 NatureCry 编码 → 第二次独立 decoder 子进程 → 再次检查。
两次 decoder 子进程仅收到文本目录和输出目录路径，不收到输入 CIF 或数据集路径。

对输入和恢复结构检查：

- 原子数和元素计数完全相同。
- 保持输入晶胞，晶格矩阵最大分量误差 `< 1e-8 Å`。
- 对同元素原子做周期性一一匹配，最大坐标误差 `< 1e-6 Å`。
- 写出 CIF 后再次解析，仍满足上述要求。
- 第二轮编码/解码满足上述要求；另报告两轮文本是否相同，文本一致不是结构通过的必要条件。

通过条件为两轮结构检查均满足标准。全部 100 个 case 留在分母中，明确记录失败阶段。
内存结构对比使用元素约束的一一匹配，不使用会允许缩放或几何变化的默认宽松 StructureMatcher。

## 输出与解释边界

保存每例输入 CIF、NatureCry 正文、输出 CIF、第二轮正文及输出，以及 audit/record。
汇总解析/恢复成功数、空间群与晶系覆盖、最大误差、精度修正与晶胞转换使用率、文件字节数和空白分词长度。
空白分词长度不是某个 LLM tokenizer 的 token 数。

100-case 测试验证指定范围内的表示与程序可逆性；不证明模型理解能力、任意自然语言解码可靠性、全 MP-20 覆盖或物理稳定性。
