# 目标：显式、可学习的 Wyckoff 约束程序

用户目标：拆解 4a/4b 等不透明 Wyckoff 标签，使模型直接看到空间/对称规则，支持 encoder/decoder 保留结构信息，并尽量让完整序列不显著长于 CIF。保留原目标，不以旧边轨道 codec 已完成为本目标完成依据。

## 候选

优先实现：全局空间群生成操作 + 每个独立原子轨道的最小仿射坐标程序 + 独立自由参数。空间群通过有限生成元闭包展开；位点通过有理仿射约束展开。无 Wyckoff 字母、无 rule ID、无邻接边列表、无按材料建立的私有词典。

使用有限算术原语 `x y z ADD NEG MUL FREE` 和可读数值。每个坐标为一棵显式表达式树，例如 `0 0 FREE 0.2`，或 `y FREE 0.3 1/4`（x=y）。生成操作使用相同表达式语法，语义与位点约束共享。不能把整个表达式算作一个 token 来制造压缩。

并行比较：显式完整操作表、少量生成元、位点稳定子生成元、最小仿射位置族。选择同时满足透明性、还原和长度的表示，不能只换编号。

## 验证要求

1. 表达式中可见自由度、固定坐标和坐标间关系。删除字母及数据库索引仍可解码，decoder 不查 Wyckoff/材料表。
2. 从原 CIF 编码，独立进程仅凭表示解码。检查元素、原子数、晶格及周期坐标，误差界明确。原始 CIF 元数据不属于晶体结构语义保留范围。
3. 保留已选十个例子，尤其 KrF2/YbBPt2。不能再次通过强行降到 P1 来掩盖数值精度和对称压缩冲突。
4. 检查原 CIF 的有限小数精度能否通过显式舍入规则恢复。如果还需要残差，必须显式保存并计入长度，报告理想骨架和原始数值的区别。
5. 初步通过后扩大到确定性 512 样本，以及晶体学位置族的合成/独立自由参数检查。失败保留，不替换样本。
6. 逐语法原语/数值计数，包括生成元、边界标记、精度/残差和几何。报告 CIF 语法单位和透明坐标程序长度，并另外提供公平结构字段基线。
7. 核查主要先例全文/方法/代码。已有 affine/Wyckoff 表达式不得冒称首创。明确当前新组合与未证明的模型学习收益。

## 完成判断

必须有可运行的具体候选、实际透明序列、独立解码验证、较广范围长度/失败审计与原文先例边界。仅有想法、代码启动或十个小例子的自洽检查不足。当前状态：调查与原型阶段，目标 active。
