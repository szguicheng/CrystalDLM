# NatureCry relational CNL interleaved pilot

This adapter freezes the first 24 IDs, in the original 100-case order, from `experiments/naturecry_roundtrip_20261001/run_001/selection.json`. The first eight are `train/seen8`; the next sixteen are `heldout16`. The remaining 76 are excluded from this pilot and are not scanned, filtered, or replaced. The earlier 100/100 relational codec round trip is a deterministic representation control, not training evidence.

`prepare.py` reads each exact source plan and encoder facts from `experiments/naturecry_inline_20261003/prepared_final`, and the corresponding complete `relational_cnl_v1` text from `experiments/naturecry_relational_20261004/run100_001/texts`. It verifies the original text against `source_facts_from_plan(plan) -> relational_codec.encode(facts, table)`, exact plan decoding, canonical rendering, source geometry, and physical audit before saving the record. For each source it makes `plus` and `minus` plans by changing only `plan["lattice"][:3]`, with each new length equal to `float(Decimal(repr(length)) * Decimal("1.05" or "0.95"))`. Angles, composition, atom count, space group, orbits, parameters, frame, rounding, and corrections stay exact. Each edited text must decode to the exact target plan and match the scaled original CIF geometry at lattice error `<1e-8 Å` and coordinate error `<1e-6 Å`.

The data adapter pins `Qwen/Qwen2.5-0.5B-Instruct` at revision `7ae557604adf67be50417f59c2c2f167def9a775`, the existing local tokenizer at `experiments/interleaved_ar_diffusion_20261002/data_002/tokenizer`, and the original `<CRYSTAL_START>`, `<CRYSTAL_END>`, `<CRYSTAL_MASK>`, `<CRYSTAL_PAD>` controls with `<|im_end|>` EOS. Capacity is `K=2560`, `STEPS=32`, `MAXLEN=8192`. Body plus END and every full trajectory are counted before data is frozen; an overflow raises an error. Nothing is truncated. The manifest records token lengths and the train/heldout length shift.

`tasks(row, split, direction, variant=0)` returns the old model seam's ordered `[G, Q1, E, Q2]` examples. The runner owns the frozen update budget and deterministic per-epoch task interleave; this adapter does not set training updates or report training results.

`score.audit(raw_text, requested)` strictly decodes the raw text once, executes the decoded geometry, and preserves the raw text and failure stage. It checks requested input-cell composition, atom count, and space-group number, finite positive volume, minimum periodic pair distance `>=0.5 Å` (with the existing `1e-10 Å` comparison allowance), and redetected symmetry with `symprec=0.01`, `angle_tolerance=5`. It does not normalize, repair, filter, or retry model text. The source reference audit retains all 24 cases in its denominator.

`grade_answer` uses the frozen `named_axis_v2` field patterns and 0.005 Å length tolerance; expected values come from the actual decoded plan/executed structure. `grade_edit(output, actual_base_text, factor)` bases E on the actual generated C1. Primary success requires exact target float lengths, every other plan field unchanged, and whole-geometry scaling within the source codec's lattice/coordinate tolerances. Absolute/relative length error and lattice/coordinate geometry error remain available as diagnostics; they do not relax primary success. The closed loop is `G + actual Q1 + actual E + actual Q2`; `flow_complete` remains a separate runner field.

Offline preparation and checks use the existing `experiments/interleaved_ar_diffusion_20261002/.venv`. No GPU, SSH, or training is used by this adapter.
