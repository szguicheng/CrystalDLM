## 1. 问题和可支持的结论

主要问题：共享 LLM 骨干能否执行“条件生成 C₁ → 读取 C₁ → 按指令生成 C₂ → 读取 C₂”的交错过程？

次要问题：在相同预训练模型、晶体表示和训练样本曝光预算下，混合模型与纯 AR 在闭环成功率、编辑成功率和结构反馈一致性上有何差异？首轮允许结果是混合方案可运行，但没有胜过 AR。

这里的文字能力限定为可靠读取、说明和执行明确指令。模板轨迹不能证明开放式材料推理；各向同性缩放不能证明材料性能改善；单种子试点不能证明模型范式优越性。

## 4. 三项任务与交错轨迹

### G 条件生成

输入自然语言明确给出规范晶胞的元素计数和空间群号。例如要求晶胞含 Ti₂O₄，空间群 136。空间群符号作为输出字段，转换采用固定后端。

条件是“精确晶胞组成＋空间群”，不是只给最简化学式，也不是此前 composition-only 实验。模型不接收真实晶格、轨道数、位点标签、目标长度或材料 ID。

输出：简短文字 → `<CRYSTAL_START>` → 晶体块 C₁。训练时 C₁ 是样本规范结构；测试时允许任何满足条件的有效结构，不要求复原唯一参考 CIF。参考匹配仅作为补充诊断。

### Q 结构读取

输入实际晶体块，要求一句或几句简短英文，报告空间群号、实际展开组成、晶胞原子数、独立轨道数，以及 a、b、c 三个边长。答案从经过审计的结构事实构造，不由另一 LLM 编造。

例如：`The cell has 6 atoms in 2 independent orbits. Its space group is 136. The lattice lengths are 4.65, 4.65, and 2.97 angstroms.` 组成另在同一回答中列出。

答案解析只提取被要求的事实；不要求与模板逐字一致。答案缺失、矛盾或无法解析都记错；先用人工写出的同义句验证评分器，不依赖 LLM 裁判。首轮使用英文监督，中文对话不是本轮考核项。

### E 可核验编辑

输入 C₁ 和自然语言要求：将全部晶格边长放大或缩小 5%，保持角度、元素、Wyckoff 标签、轨道顺序和分数坐标不变。

规范目标：用 Decimal 从输入字符串的两位小数边长计算 `a'=round(a×s, 2)`，b、c 同理；s 取 1.05 或 0.95；舍入使用 ROUND_HALF_EVEN。直接替换 abc 行，其余结构字段保持不变，不再次精修、标准化或重新编码。

各向同性缩放保留晶系的度量关系，适合作为跨晶系的最小操作。但 ±5% 与舍入可能影响距离合法性，因此数据构建要审计两个编辑版本。首轮不把它当成稳定结构设计任务。

每个材料生成两个方向的监督变体，训练采样时按材料 ID 的固定哈希与访问次数交替选择方向，测试按固定哈希选择一个方向。选择与模型输出无关。

完整训练轨迹：`用户条件 → AR 触发晶体块 → C₁ → AR 读取 C₁ → 用户编辑要求 → C₂ → AR 读取 C₂`。每轨迹拆成 G、Q₁、E、Q₂ 四个前缀—目标例子；只监督当前目标，前缀保留已完成结构，不给当前或未来晶体的干净答案。

训练使用两个固定指令措辞，验证使用第三种，测试使用第四种；语义均相同。划分以材料为单位，措辞改写只检验有限改写鲁棒性，不能据此宣称开放式语言理解。指令模板与数据清单同时冻结。

## 5. 晶体边界与扩散定义

增加四个共同控制 token：`<CRYSTAL_START>`、`<CRYSTAL_END>`、`<CRYSTAL_MASK>`、`<CRYSTAL_PAD>`。不添加元素、Wyckoff 或数字专用词表。晶体容量 K=256；干净块为字符串 token、一个 END 和后续 PAD。START 不参与块内扩散，由 AR 文字模式生成。

两模型共享控制 token 和初始化。为每个晶体 token 加 33 项时间步 embedding，H 使用 k=0…32，A 使用 k=0；初始时间 embedding 全零，容量一致。文字 token 不加时间 embedding。后续文字读取完成块时使用 k=0，END 后的 PAD 不进入后续上下文。

H 的前向过程：训练均匀采样 k∈{1,…,32}，t=k/32；每个块位置独立以概率 t 替换为 MASK，其他位置保留原 token。END 和 PAD 同样参与噪声，不暴露真实结束位置。每次训练仅破坏当前目标块；前缀不加噪声，也不监督未来块。

H 的采样：从 256 个 MASK 开始，k 从 32 到 1。每一步预测当前 MASK 位置的干净 token 分布；每个 MASK 位置以 1/k 的概率释放并从该分布采样，否则仍为 MASK。已释放位置保持不变；最后一步释放全部剩余位置。这是线性吸收态 MASK 过程的反向采样近似，不使用 confidence-remask 或随机回填几何。

词表约束只禁止清洁输出含 MASK/START 等不合法控制符，不基于目标结构或空间群做 oracle 掩码。两模型使用相同静态控制符规则。解析时要求恰好一个 END、END 前无 PAD、END 后全为 PAD；H 的违反项作为长度/边界失败，不能丢掉尾部后伪装通过。

A 在晶体模式逐 token 生成，到 END 停止；剩余 PAD 由序列存储格式补齐。PAD 是 H 的长度表示成本，因此额外报告 H 的边界错误率，速度比较采用实际端到端时间而不以 256/32 推导加速。

## 6. 注意力与损失

H 当前晶体块的 query 可以读取整个噪声块和完整前缀；前缀 query 不能读取当前晶体块。已完成的晶体块也保持块内双向注意力，块间只读取此前内容。文字目标保持因果关系，允许读取此前完整晶体，禁止读取未来文字或晶体。A 所有目标均使用因果 mask。两个模型均不能通过 padding mask、位置编号或 KV 缓存获得当前目标的真实结束位置。

训练晶体位置预测采用同位置干净 token 标签，不能套用 causal LM 默认的 next-token shift；文字目标仍采用 shift。H 生成完成后重新计算当前完整晶体的上下文表示，不复用旧噪声的 KV。首轮两模型均不做 KV 缓存优化，以减少实现变量；效率结果只适用于这个原型实现。

文字损失按被监督的文字 token 数归一化。H 晶体损失赋非 PAD token 权重 1、PAD 权重 0.1，并按整个干净块的总权重归一化；A 只按其字符串和END的监督token数归一化。这只影响训练，评估绝不提供干净块长度。

- A：对字符串与 END 采用加权 next-token CE，不监督存储用尾部 PAD。
- H：对 MASK 位置采用加权同位置 CE，时间步权重 32/k；非 MASK 位置不计去噪 CE。由原始干净标签决定的权重仅用于 loss，不能回流到注意力或模型输入。

联合目标为 `L_text + λ L_crystal`，λ=1；每个更新批次均衡包含文字例和晶体例。PAD 降权是明确的工程选择，本轮不把这个重加权目标当作严格文本似然，也不跨两模型比较 perplexity 来宣称优势。分别记录文字、晶体正文、END、PAD 和各噪声区间的损失。训练时Q₂读取干净参考C₂，实际闭环读取模型C₂；这处teacher-forcing与生成输入的差异通过独立队列和闭环队列分别测量，首轮不做在线生成轨迹回灌。

## 8. 评估队列和分母

256 个冻结测试材料，各做一次条件生成、一次参考结构读取、一次参考结构编辑，以及一次完整生成闭环。生成主采样配置：temperature=0.8，top-p=1；文字 greedy；H 晶体32步，A晶体最多256个输出 token。AR 触发文字和每段读取文字最多160 token，未按时结束或未触发记失败。正式推理随机 seed=20261002，并按材料 ID 派生子 seed。两模型都不重试、不筛选后补齐数量。

| 队列 | 输入与计分方式 | 要隔离的问题 |
|---|---|---|
| G | 同一组成/SG条件，分母256 | 能否独立生成结构 |
| Q-reference | 同一真实规范结构，分母256 | 能否读取结构 |
| E-reference | 同一真实结构＋编辑指令，分母256 | 编辑是否正确 |
| Closed-loop | 实际生成 C₁ → 读 C₁ → 编辑 C₂ → 读 C₂，分母256 | 错误是否在交错过程中累积 |
| Q-swap | 替换已有晶体后提问，分母256 | 是否依赖实际晶体 |

Closed-loop 中，C₁/C₂ 无效时该例的完整闭环失败，后续跳过项仍保留在分母。另报告有效 C₁ 条件下的 Q/E 成功率，但不能只报告这种幸存者子集。后续文字的答案对照实际 C₁/C₂，不能拿训练参考答案代替。

Q-swap 以固定测试材料循环置换构造。用户明确要求读取替换后的结构，忽略之前的设计要求；插入与旧结构不同的 Cswap，重新计算上下文并报告空间群、组成、边长等变化。配对时保证至少两个被考核字段改变。另有相同问题但移除晶体的 Q-no-crystal 对照；正确拒答也记录，但不能算结构事实命中。置换及问题列表在模型测试前冻结，首轮不声称它证明复杂推理。

## 9. 评分规则

结构“条件有效”必须同时满足：

1. 边界正确，所有字段可解析且有限；角度合法、边长为正、晶格体积为正。
2. 头部组成、Sites 总数与轨道 multiplicity 累加的真实元素数完全一致，且与用户指定晶胞组成一致。
3. 空间群字段与请求一致；标签和 multiplicity 对该空间群合法；坐标满足声明的 Wyckoff 轨道约束。三位小数引入的分数坐标约束误差容许 1e-3，周期等价关系按 modulo 1 比较。代表坐标只要求有限，不限制在[0,1)：例如6h的(x,2x,1/4)可以写成(0.814,1.629,0.250)。保留原字段，审计使用周期等价比较。
4. 晶格满足声明晶系的度量关系（长度比较容差0.01 Å，角度0.01°），官方 decoder 成功，实际展开计数与声明相同；周期最小原子间距至少0.5 Å。
5. 用固定 symprec=0.01 Å、angle_tolerance=5° 重新识别解码结构空间群，识别结果须等于请求空间群。若只满足声明群但被识别为更高群，单列为对称性提升，不混入“精确空间群成功”。

0.5 Å 是发现严重重叠的粗检查，不是化学有效性或稳定性判据。decoder 可能进行几何处理，因此分别保存原始字段审计结果与解码后结果，不因投影后合法就覆盖原始错误。

Q 成功：组成、原子数、空间群号、轨道数均完全正确；a/b/c 与当前字符串字段差不超过0.005 Å。缺失、矛盾、数值无法解析均失败，同时列字段准确率和全部字段一致率。

E 成功：边长与 Decimal 生成的两位小数目标逐字段一致；角度、元素、位点标签、轨道顺序、分数坐标与输入完全一致；头部一致；解码后的元素计数保持且通过合法性检查。不要求字符串空格一致，不重新规范化后放宽错误。另报告编辑后精确 SG 识别结果，防止把量化导致的对称性变化隐藏。

主指标是 Closed-loop 全部步骤同时成功的比例。G、Q-reference、E-reference、边界失败、结构失败、条件失败、Q-swap 和解码后几何变化是诊断指标。所有模型失败、超时和解析失败都保留在相应256个样本的分母。

## 10. 推进阈值和比较方式

以下阈值是首轮工程推进标准，不是统计功效计算或文献结论：H 的 G 条件有效率≥50%，Q-reference 全部字段正确≥90%，E-reference≥80%，Closed-loop≥30%，Q-swap全部字段正确≥85%，且Q-swap较Q-no-crystal高至少30个百分点。必须逐项报告，不能把高 Q 准确率替代闭环成功。

达到阈值说明该小模型与数据设置下机制有可用信号，值得扩大；不代表强材料推理或物理稳定性。未达到就报告当前设置未验证成功，先据分阶段指标定位，不直接宣告 AR＋Diffusion 不可行。

报告两模型逐样本 paired 成败、绝对百分点差、各成功率 Wilson 95% 区间，以及按材料 ID 做10,000次 paired bootstrap的差值区间（bootstrap seed=31415）。模板和字段不是独立样本，不把它们当作扩大后的 n。一个训练seed下的区间只反映该检查点的测试样本变化，不覆盖训练随机性。

只有 H 达到机制阈值，且至少一项 G/E/Closed-loop 比 A 高10个百分点，或质量接近时有实测端到端成本优势，才值得做三训练seed确认。质量“接近”在此只指闭环观察差不低于−5个百分点，不能称已证明非劣。若机制通过但 AR 更好，保留这一结果；不自动加新模块或更换表示。

首轮无需证明速度优势。报告从输入到文字/晶体完成的中位数和P95耗时、forward次数、有效结果数和 GPU 型号，比较包括失败尝试；每有效结果的成本在零成功时记为不可用。

## 11. 实施与留证

实施优先复用现有 PLaID codec、CSV 和结构匹配工具；新增最少的数据构建、混合训练/采样和评分入口，不建立框架。入口实现后才给可运行命令。

数据阶段保存源哈希、合格/排除清单、材料划分、规范晶体与编辑目标、模板版本；模型阶段保存base/tokenizer revision、包版本、随机seed、配置、checkpoint、损失曲线与资源记录；测试阶段保存每例原始文字、所有晶体块、失败原因、审计记录和可解码 CIF。关键执行结果保存到本实验目录的新 `run_001`，不覆盖旧实验产物。

最小实现检查必须覆盖：未来答案无法影响当前logits；H 同位置标签与 AR shift；原始长度不泄漏；反向步骤最后无MASK且不改已释放位置；END/PAD错误被计失败；组成/Sites矛盾不能被decoder忽略；编辑目标和评分器可由人工构造正确/错误例独立验证。用一个小型assert检查文件覆盖这些关键行为，不为每个辅助函数创建测试套件。

实施顺序：数据与评分器 → 8材料机制检查 → 两模型共同预算冻结 → 正式训练 → 固定测试 → 是否进入确认实验。下一步首先实现数据构建和评分器，不提交训练任务。

## 12. 本轮明确不做

不改NatureCry，不训练新的tokenizer，不增加晶体latent/VAE或连续坐标分支，不采集论文全文配对数据，不生成不可核验的长推理链，不做DPO、MLIP弛豫、S.U.N.或DFT。机制闭环通过后，这些分别立新协议。
