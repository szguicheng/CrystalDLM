# 边轨道 tokenizer：10 个 CIF 双向转换结果

2026-09-17，Burgundy CPU 节点 cpunode-058，Slurm 568470。最终完整测试用时约 14 秒。复用一个 CPU/tmux 分配完成接口检查、故障诊断及最终测试。

## 结论

**加入晶格与自由坐标后，10/10 个原始 CIF 完成结构与近邻图往返恢复；只保留离散 prototype，不能唯一确定具体材料的几何。** 位点/边记录数量减少，但目前自包含 JSON 总体比原 CIF 和全展开图 JSON 更大。

## 测试流程

输入 CIF → encoder → 自包含 JSON → 独立 decoder 进程 → 输出 CIF → 重新解析 → 再次 encoder/decoder。解码进程只读取 JSON。保存输入晶胞，不做标准化、原胞/常规胞转换或坐标理想化。CIF 输出以 P1 列表完整列出所有原子。

源数据为固定版本的 WyFormer MP-20 训练集。按材料 ID 的 SHA256 排序，对每个尚未出现的数据集空间群取首个材料，直到 10 个，失败不换样本。初次与最终样本清单逐字一致。来源、输入 SHA256 见 results/selection.json。

## 压缩究竟发生在哪里

- 位点记录：90 → 52，减少 42.2%。
- 边记录：888 → 336，减少 62.2%。
- 位点与边记录合计：978 → 388，减少 60.3%。
- 上述不包含全局操作表/约束字段开销，也不是语言模型 token 数或信息论码长。

|---|---:|---:|

完整编码相对同信息全展开图 JSON 增大 81.9%，分别 gzip 后仍增大 28.2%。10 个单文件的字节数分别相加，不使用不同打包方式制造压缩优势。
原始 CIF 含有不同文本开销且不显式存图，不能只靠与 CIF 的大小比值评价图编码。当前操作表和仿射位点稳定子内联保存，开销已全部计入，没有宣称词表共享后的潜在压缩为实测收益。

## 暴露的问题：近似对称与严格保真

初次 symprec=1e-5 Å 时，只有 5/10 通过严格结构检查。四例在原子对称映射处失败，一例在解码后偏移约 5.03e-6 Å。诊断显示相关操作对原始坐标造成约 4.23e-6 到 6.16e-6 Å 的残差。

将统一识别容差收紧至 1e-7 Å 后，同样 10 个样本全部通过。5 个样本保留的空间群降低，其中 AlIn(CuS2)2 变为 P1，原子和边均无对称合并收益。这是输入有限精度数值上的识别结果，不代表材料真实物理空间群改变。

如果后续坚持高对称标签，需要明确选择允许多大的几何理想化误差，或额外保存每个原子的偏差。本实现没有增加残差通道，也没有暗中把输入理想化。失败记录与容差诊断保留在 evidence/。

## 只有 token 能否恢复完整结构

- 所有 prototype 均为整数/字符串/容器，不夹带晶格或自由坐标数值。
- 10/10 在不给 geometry 时明确拒绝解码，未通过查表或访问原 CIF 补齐信息。
- 在有自由坐标的样本上，改变允许的自由参数能得到不同坐标，而离散 prototype 与抽象图保持不变。
- 对所有 10 个样本，把晶格整体放大 1.01 倍，体积变为 1.01³ 倍，离散 prototype 和抽象连接保持不变。
- 去掉全部边记录后，10/10 的位点＋几何仍恢复相同原子坐标，恢复出的显式边集合则为空。

因此，坐标恢复的必要信息在全局对称、位点约束和连续几何中。边 token 额外保存近邻拓扑，其价值不能仅用“可以恢复 CIF”来证明。本次尚未证明生成质量、化学稳定性或模型学习收益。

## 使用

```bash
python cif_codec.py encode results/mp-30009/input.cif my_encoding.json
python cif_codec.py decode my_encoding.json my_decoded.cif
```

编码 JSON 包含 prototype 与 geometry。每个材料目录还提供拆分的 prototype.json、geometry.json、输入/恢复 CIF 及全展开图基线。requirements.txt 为本次实测依赖版本。

范围限于本次 10 个有序、满占位样本。CIF 注释、标签、热参数、磁性和其他实验元数据不保留。核心操作平移有小分母有理数限制，不能推广成任意原点/任意 CIF 已验证无损。
