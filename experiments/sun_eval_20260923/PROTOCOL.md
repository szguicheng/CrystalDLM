# Composition-conditioned SUN pilot

Frozen before energy/novelty results, 2026-09-23. This adds an evaluation to the completed full-MP20 experiment, without retraining or resampling.

- Inputs: seed17 best-validation checkpoints' existing remask test outputs, 512 attempts per representation, identical composition conditions. All attempts remain in denominators.
- Evaluate the existing prediction-only lattice-projected outputs. The existing basic+symmetry gate gives 119 explicit and 145 Wyckoff candidates. This additional gate makes this a **valid, composition-conditioned SUN pilot**, not a reproduction of unconditional paper scores. Gate failures count as unsuccessful attempts; they are not silently dropped.
- Relax with CHGNet package 0.3.8 / model 0.3.0, CUDA, FIRE, variable cell, fmax=0.1 eV/A, at most 500 steps, at most 120 seconds per candidate. No symmetry constraint in relaxation. Record convergence and final space group. Unconverged cases are not counted in the headline conservative score; a separate endpoint score is diagnostic.
- Stability proxy: CHGNet total energy per atom minus the Materials Project 2023-02-07 reference hull energy per atom. Reference is Matbench Discovery Figshare file 48241624, MD5 60d19d691fa1d338aa496a40a9641bef. This follows FlowMM's CHGNet proxy calculation, not corrected DFT evaluation. Report thresholds <0, <0.08, <0.10 eV/atom separately; the latter two allow metastability.
- Novelty: compare structures against all 27,136 canonical MP20 training structures used in our experiment. Additionally report train+val novelty (36,183 references). This is dataset-relative novelty, not novelty against all Materials Project or global knowledge.
- StructureMatcher: ltol=.3, stol=.5, angle_tol=10 degrees, primitive_cell=True, scale=True, attempt_supercell=False, default species comparator. Composition hash prefilter; never deduplicate by formula alone. Record this loose discovery-matching tolerance separately from our earlier tighter reference-recovery metric.
- Uniqueness: within each model's generated candidate set, first representative in material-id order; for SUN, filter stable+novel then deduplicate (so an unstable representative cannot suppress a stable duplicate). Report raw counts and denominator, not a product of independently estimated S/U/N percentages.
- CHGNet's training data overlap MP20; this is a learned energy proxy, not independent DFT evidence or synthesizability proof. One model seed and one sample per condition, so this cannot establish within-condition diversity or robust cross-seed superiority.
- All ML, hull loading and structure matching run in a Burgundy Slurm compute allocation with tmux; local work is code, source verification and file transfer.

Sources checked: [SymmCD section 5.2](https://openreview.net/pdf?id=xnssGv9rpW), [WyFormer table 1 and appendix G](https://arxiv.org/html/2503.02407v4), [FlowMM hull implementation](https://github.com/facebookresearch/flowmm/blob/main/scripts_analysis/ehull.py), [FlowMM relaxation implementation](https://github.com/facebookresearch/flowmm/blob/main/src/flowmm/chgnet_.py), [Matbench data](https://figshare.com/articles/dataset/22715158).
