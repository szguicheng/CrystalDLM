# 离散 prototype 与自由几何分离：验证结果

## Material Passport

2026-09-09（香港时间）；Burgundy Slurm 533539，队列013成功，约41.5秒；使用之前512个训练结构。没有使用预留验证集，也没有生成模型训练。

## 当前 token 表示

- 全局：空间群、Hall编号、当前设置下的Seitz操作表；旋转为整数，平移为整数分子/分母。
- 每个不等价原子：元素、Wyckoff标签、仿射site-stabilizer记录。每项记录包含操作编号及让该操作精确固定位点的整数平移。
- 每条边轨道：源节点、目标节点、操作编号和三个整数cell-image分量。
- 单独的几何载荷：晶格及自由坐标向量，不进入离散prototype。

site stabilizer是已有晶体学对象。把其旋转与平移分别平均，得到P与b，位置族写成`q=b+P*u`。P、b由离散记录确定，连续自由参数u由几何模型处理。rank(P)给出实际自由度；目前u存为冗余3维向量，没有把3维全算成物理自由度。

## 这些结果意味着什么

该表示已经可以独立定义“对称位置族 + 周期连接关系”，然后由另一份连续载荷实现具体几何。因而具备了“prototype先给出、几何后确定”的表示接口。

随机几何实例只是反例检查工具，不是新材料样本。它们不必继续满足原始4.5Å截断邻接、不保证原子不重叠、也不保证合理键长或稳定性。通过的是抽象周期图不依赖源自由坐标，不能外推成生成几何已有效。

也没有证明这是新的晶体学表示基础：ASU、Wyckoff、site stabilizer、Seitz操作和带平移的周期图都已有。可研究差异仍是它们作为离散边轨道token及条件生成接口的具体组合，需对照已有ASU/仿射边方法。

## 与已有模型证据的关系

前面图骨干在同权重下保持输出/梯度一致。相对逐邻居ASU对照，512图时省44.6%峰值分配内存、慢11.7%。这说明存在已测到的组件级用途，尚非新prototype的训练结果。

下一步必须从不含真实自由坐标的prototype构造模型条件，让模型接收noisy自由参数，并明确图和晶格是否作为条件；不能沿用含clean坐标的缓存却把它说成生成实验。离散边token的学习、条件几何去噪及最终采样质量均保持未验证。
