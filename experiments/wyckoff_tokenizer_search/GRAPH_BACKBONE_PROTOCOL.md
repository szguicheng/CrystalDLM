# 边轨道网络：功能等价性与资源验证

## Material Passport

2026-09-08；表示/模型组件实验；输入为已通过图往返检查的 512 个训练结构；原胞完整图作为基线。此次不评估预留验证数据，也不训练生成模型。

## 需要证明什么

图记录更少必须转化为真实的模型计算收益。使用同一组参数、三层径向 message passing、相同原子特征和一个向量输出头，对比：

- 完整原胞图：对每条有向周期近邻边计算消息和方向向量；
- 边轨道图：每个有向边类别只计算一次消息，按每个代表原子的邻接重数加权；方向使用该类全部邻居位移的和。

若一个边类别包含 k 个邻居，向量和可写为 `sum_R @ q_target + sum_translation - k*q_source`，再变换到笛卡尔坐标。因此压缩路径的 forward 不需要生成这些邻居的完整坐标和边。

轨道级图池化按原胞原子重数加权，而不是把每个轨道等权处理。这样可与完整图的每原子平均比较。

## 验证设置

- 前 32 个训练结构，FP64；检查 clean 坐标以及 scale=0.015 的分数坐标扰动。
- 扰动先经位点 stabilizer 的平均旋转矩阵投影，限制在对应 WP 的切空间内；晶格保持不变。
- 同一权重和相同扰动，比较图级标量特征、ASU 代表处的笛卡尔向量输出、对扰动变量的梯度、全部模型参数梯度。
- 判据：PyTorch allclose，rtol=1e-7、atol=1e-8，并报告绝对误差。
- 512 个训练结构，FP32；交替运行两条路径，4 轮，每轮预热3次、计时10次 forward+backward；记录 CUDA 同步后的耗时和峰值 allocated memory。
- 两条路径都保留相同输入缓存，显存比较因此不会把删除基线输入缓存的额外收益计入。
- 编码和数据准备耗时单独记录；不混入网络 forward/backward 提速。

## 适用边界

这是一类共享参数、径向标量消息与等变向量输出的图网络。通过它不能证明任意 GNN 都可无损换成轨道图；例如未经正确变换的方向嵌入不能套用此结论。

扰动期间使用同一个 clean 近邻拓扑。此处只验证固定拓扑上的计算等价性，不声称已经完成动态邻居更新、离散边生成、跨 WP 转移、训练后的扩散采样或材料稳定性验证。

若通过，再确定实际 conditional denoising 任务及动态拓扑处理，验证生成质量。此次若仅有文件压缩或输出相近而梯度不一致，不视为模型用途通过。
