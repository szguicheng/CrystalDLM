# 首组配对模型结果：未证明完整占位非线性编码有用

本实验是给定组成和空间群的离散占位预测，使用cap256范围内26,086个训练结构、固定2,048个验证结构。两个模型均799,360个参数，seed=17，各训练2,000步，使用相同完整合法候选。成功Slurm作业532829，stingy/gpu-a100-05，耗时5分02秒。

| 指标 | 逐WP可加打分 factorized | 完整占位非线性 compositional |
|---|---:|---:|
| 平均profile NLL | 0.624017 | 0.623681 |
| 非平凡候选元素准确率 | 75.09% | 75.32% |
| 独立argmax带标签结构exact-match | 56.25% | 56.93% |
| 固定位置互斥合法率（非几何有效率） | 87.55% | 88.13% |
| 未见正例profile的命中 | 11 / 81 | 5 / 81 |
| 相同精确联合解码后结构exact-match | 61.23% | 61.43% |

联合解码作业532849对两者采用相同的零自由度位置bitmask exact MAP。该解码器经100组独立穷举案例核对；只保证已编码固定位置的跨元素互斥，不保证几何或稳定性。

联合解码后的差值仅为 **+0.195个百分点**。按验证结构配对bootstrap的95%区间为 **[-1.123, +1.563]个百分点**，跨过0；这是单训练种子的开发结果，未估计训练随机性，也不是最终测试集结论。两者NLL几乎相同，未见profile上的小样本结果反而较差。

## 当前决策

不把“给完整占位向量加一个非线性候选编码器”认定为有用的新tokenizer。该架构可以训练，但首组证据不足以支持额外收益。文献方面，Parackal et al. 2024已有合法Wyckoff枚举加Wren排序，Wren也已有非线性multiset建模，因此这一候选的创新边界偏弱。

这不证明所有完整占位模型都无效，也不能证明更长训练或其他参数一定无用。当前选择是不优先扩大其算力投入，而转向真正改变分词规则的有界候选。

## 下一候选

只在训练集上学习同一元素的无序Wyckoff子集合合并，每个新token最多覆盖4个orbits，保留全部基础WP作为回退。它不需要母相、畸变模式或新的晶体学概念。

下一检查必须包括：

- 全部处理数据的离散编码/解码正确性与输入orbit排列不变性；
- 与原始逐orbit编码、简单`(WP,count)`重复计数编码分别比较；
- 如果收益主要来自重复同一WP，不得把已有计数表示重新命名成创新；
- 只有表示检查通过后，才做同条件模型对照；压缩率本身不能完成当前目标。

测试集尚未用于模型性能评估。当前研究目标保持未完成。
