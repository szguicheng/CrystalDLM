# 直接预测 Wyckoff 编码单元的开发诊断

前两组候选 profile 打分实验均未显示可靠收益。本实验保持同一组成与 SG 条件任务，把模型训练目标改为独立的 canonical word 槽位：计数词与无序集合合并词。先只比较这两个强相关方案。

## 预测单元与输入

- 使用已固定的 `word_candidates/data.pt`，相同 cap256 上下文和 26,086 条训练结构。
- 每种元素给 17 个槽位，该上限来自完整理论候选的最大 orbit 数，两个变体相同。PAD 是模型需要预测的符号，不输入目标词数，不按目标长度屏蔽 attention。
- profile 内词按已有 codec 的确定顺序排列；使用槽位位置嵌入区分同一元素内的预测位置。元素间不设顺序嵌入。
- 随机遮盖词（含 PAD），25% 概率全遮盖；验证全遮盖，仅给组成与 SG。训练直接最小化被遮盖词的交叉熵。
- 两者使用同样的语义词编码模块、Transformer、初始化、样本顺序、槽位数、掩码抽样与参数量。词表分割是实验变量。

## 相同的合法读出

每个 `(SG,N)` 的可预测词只由该上下文完整候选的词并集决定，与目标 profile 无关。模型输出各槽位的词概率，将每个候选的 canonical word 序列（含 PAD）逐槽位 log probability 相加，再在完整候选集合上归一化。两者使用相同的跨元素固定位置排他精确 MAP 解码。

主指标是相同合法读出后的完整带标签 protostructure 匹配率；平均 profile NLL 用于选择检查点。原始词序列匹配率也记录，但由于各编码 PAD 比例不同，不用其独立证明收益。不同编码的词级训练 loss 不直接横向比较。

## 预算与决策

- 同一 3 层、96 维、4 头 Transformer，batch 32，AdamW 3e-4，seed17，每种 2,000 步。
- 固定相同 2,048 个验证结构；不读模型测试集结果。
- GPU smoke 检查目标词全遮盖泄漏、候选序列分数 gather 一致性、有限梯度，以及既有固定位置解码的穷举对照。
- 若集合合并仍无匹配率或实际资源优势，不为这一小差异扩展同架构预算。若有明确正向信号，再核实多种子和直接多步去噪/生成。

本实验仍含完整候选枚举读出，不是无枚举的生成模型；无几何与稳定性评估。它可以支持或削弱词级分组的建模假设，不能独自证明完整 conditional diffusion 方法有效。
