# 扩大数据的条件去噪试验：数据与训练预设

2026-09-09。动因是334/84内部pilot出现明显训练—开发差距；不是针对开发结果改token定义或挑选更有利checkpoint。

## 固定数据范围

- 训练候选：固定版本WyFormer MP-20的全部27136个原始train.csv结构。此前84个内部pilot验证结构本来属于这个原始训练集，现在进入训练候选，因此旧84个结构不能再用于泛化结论。
- 开发候选：之前既定cap256数据中的2048个官方validation结构，仍按material_id SHA-256排序选取。只复用其ID，不依据本实验成绩再筛选。
- 排除条件预先固定：CIF/标准化/图往返/整数prototype编译失败，或没有内部几何自由度。逐结构保留失败原因，训练启动前检查数据审计；不得按预测好坏删除结构。
- 图的4.5Å半径、空间群标准化参数、整数prototype定义、自由坐标分离与指定晶格条件不变。
- 官方test和预留6620结构不作模型评估。

## 固定学习设置

沿用同一径向向量网络、Cartesian sigma=0.1Å、WP切空间噪声与原点模式去除、AdamW lr1e-3/weight_decay1e-5、零初始化最终向量层、batch最多32。

使用seed17，20000个更新；只以最后一步作为主结果。每2000步记录开发误差，不据此延长训练或选择中间checkpoint。批组按结构数比例抽取，使结构的期望权重一致。增加步数是为覆盖更大训练集；不宣称与小pilot使用了相同训练预算。

开发集每结构8套固定噪声，比较identity基线，并用同一已训练参数核对ASU/edge-orbit路径的预测。按结构汇总配对误差与区间；本阶段仍是开发性单seed试验。

## 结论范围

若泛化改善，支持“该离散prototype可以作为可学习的条件几何去噪接口”。不代表新增tokenizer带来了预测质量优势，因为两条图路径在同参数下本应等价；其已测作用是边压缩的显存收益与时间权衡。

单噪声级实验仍不是完整扩散生成；噪声时间条件、采样和材料有效性/稳定性需分别验证。
