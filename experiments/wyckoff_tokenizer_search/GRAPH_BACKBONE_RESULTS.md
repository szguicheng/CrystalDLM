# 边轨道图网络：已验证的计算收益与尚未成立的创新性

后续强对照：`ASU_CONTROL_RESULTS.md` 已将节点约简与边约简分开。相对逐邻居 ASU 图，512图时新增边约简减少44.6%内存，但慢11.7%；下文1.57倍提速仅相对原胞完整图。

## Material Passport

- 日期：2026-09-08。
- 执行：Burgundy Slurm 533539，A100-SXM4-80GB，tmux 队列 010、011 均成功完成。
- 输入：前一轮编解码检查中的 512 个训练结构，全部采用原胞完整图作基线；不使用预留验证组。
- 模型：94529 参数、3 层径向标量消息传递、一个笛卡尔向量输出头；相同权重比较完整图与边轨道图路径。没有训练生成模型。
- 范围：固定近邻拓扑、固定晶格、保持 WP 的坐标扰动。不是完整扩散采样或生成质量评估。

## 功能等价性

完整图逐条计算邻居消息；边轨道图每个类别计算一次，按源代表原子的邻接重数加权。向量输出使用该类全部邻居方向之和，通过预先计算的仿射系数得到。轨道级池化按原胞原子重数加权。

32 个图的 FP64 检查中，clean 和 WP 切空间扰动两种情况下，图级特征、代表原子处的向量输出、扰动变量梯度和全部参数梯度均通过 rtol=1e-7、atol=1e-8。最大输出差异约 6.7e-16，最大梯度差异约 1.2e-17。

之后对全部 512 个图用另一随机种子做 FP32 检查：

| 指标 | 两条路径的最大绝对差异（clean / perturbed 中最大值） |
|---|---:|
| 图级特征 | 4.77e-7 |
| 代表原子向量输出 | 6.86e-7 |
| 坐标扰动梯度 | 9.25e-10 |
| 参数梯度 | 3.73e-9 |
| 向量经空间群操作展开后，与全部原胞原子的输出比较 | 6.86e-7 |

这些检查没有因为所有位点固定而退化：2390 个轨道中，0/1/2/3 自由度的数量分别是 833/649/470/438。投影扰动最大绝对值为 0.05064（分数坐标），引起的向量输出变化最大约 0.1926。

等价性是本实现的正确性结果，不是独立创新点。相同函数的梯度一致可以从函数等价自然得到，不能仅因前人没列出梯度测试就声称方法不同。

## GPU 资源测量

整个 batch 包含 512 个图；FP32；每个路径预热 3 次、连续测量 10 次 forward+backward，4 轮交替顺序。表中时间取 4 轮中位数。

| 指标 | 原胞完整图 | 边轨道图 |
|---|---:|---:|
| 节点 | 5219 | 2390 |
| 有向边/有向边类别 | 114814 | 26894 |
| 每批 forward+backward | 10.91 ms | 6.94 ms |
| 峰值 PyTorch CUDA allocated memory | 803361280 B | 214930944 B |

在这个设置下，网络 forward+backward 提速 **1.57 倍**，峰值分配内存下降 **73.25%**。两条路径都保留相同输入缓存；未将删除完整图输入缓存的额外收益计入。

这些数字不包括在线构图/编码或文件传输，不能外推为完整扩散提速。此次同时准备两种路径的数据花了 17.56 秒，未拆分单独的编码耗时。若每个去噪步骤都重新构图，必须另测整体成本。

## 创新性核查改变了结论

后续阅读发现，Ruff et al. 2024 的 ASU 图网络与其官方 coGN 实现已经包含 ASU 节点、multiplicity-aware readout，以及带 cell translations / affine matrices 的边。因此，ASU 节点、仿射边标签或“利用对称性减少 GNN 计算”均不能作为首次贡献。

进一步核查官方 v3.0.1 的 `kgcnn/crystal/graph_builder.py::to_asymmetric_unit_graph`：函数选择以 ASU 代表为中心的邻居边后，逐条 `add_edge`，并复制相应 `symmop`；没有 edge multiplicity/count 合并。故该实现保留邻居 occurrences，我们测试的路径进一步按边轨道合并。这个判断来自构图代码，不能仅由论文中允许 multi-edges 的描述推出。

因此当前状态是：**计算收益已在这一模型组件上验证；新 tokenizer 的创新性与生成用途尚未验证。** 当前代码还没有生成离散边 token，不能把骨干 benchmark 写成新的完整扩散模型。

## 下一步判据

1. 已确认 coGN 官方 ASU graph construction 逐条保留邻居边；这限定了可研究的差别，不构成全球新颖性证明。
2. 加入逐邻居 ASU multigraph 作为更强基线，分离已有节点约简收益与新增边约简收益。
3. 在实际条件去噪使用前，处理动态邻接或明确图条件；不能让由目标 clean 结构得到的邻接图成为隐含 oracle。
4. 只有明确实际可生成的 token 单位和与已有工作的差异后，才决定是否进一步实现完整训练/采样。
