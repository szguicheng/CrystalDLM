# ASU 逐邻居对照：隔离新增边压缩收益

2026-09-08；固定拓扑的网络组件试验，无模型训练或生成样本。使用同一 512 个训练图及其前 32 个图，不使用预留验证组。

新对照按已有 ASU 图的粒度构造：仅选择以每个不等价原子代表为源的完整原胞邻居边，把目标映射至轨道节点，但为每个邻居保留仿射像、平移和独立消息计算。方向在本实现统一为 outgoing；此处复现的是边记录粒度，不是 coGN 的全部架构、超参数或成绩。

比较三条路径：原胞完整图、ASU 逐邻居图、边轨道图。三者继承完全相同的参数构造器。新增对照的邻居数逐节点与边轨道加权 degree 核对相等。原胞和 ASU 路径不做无意义的消息乘一操作；边轨道路径保留必要的重数加权。ASU 向量直接使用逐边位移，不计算多余的方向和。

- FP64：32 图，clean 与 WP 切空间扰动 scale=.015；输出、向量和两类梯度与完整图比较，atol=1e-8、rtol=1e-7。
- FP32：512 图，同样两种坐标状态；atol=3e-5、rtol=3e-4。
- 随机种子43，同一权重；网络仍为3层、宽64。
- 性能：32 与512图两种 batch，交替顺序4轮，每种预热3次并测10次前向+反向。GPU同步后计时，记录峰值PyTorch allocated memory；缓存对三种路径一致。
- 主要比较：边轨道相对 **ASU 逐邻居图** 的时间/内存差异。不得把相对原胞完整图的全部收益写成新增边压缩的贡献。

通过仍只证明这一组件的固定拓扑功能等价与开销。动态构图、实际条件去噪/采样及离散边token的生成作用保持未验证。
