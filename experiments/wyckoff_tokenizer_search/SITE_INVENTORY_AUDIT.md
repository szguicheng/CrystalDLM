# 位点对称性 inventory：表示检查与下一步判据

## Material Passport

- 类型：确定性表示审计；不是模型性能验证。
- 输入：既有 MP-20 cap256 完整候选集、固定 PyXtal 1.1.4 标准设置表、精确仿射 stabilizer 检查得到的 32 类点群元数据。
- 运行：Burgundy `533530`，`cpunode-058`，tmux 队列 `003-site-inventory`，2026-09-08。2 CPU、8 GB 内存，无 GPU。脚本运行约 1.86 秒，队列任务约 6.21 秒。
- 标签范围：只统计训练集；未读取保留验证组的模型性能。
- 结论等级：表示的预算可确定性与有限候选集往返已验证；创新性有限文献检索；模型收益未验证。

## 候选的具体含义

给定空间群 G，对每个元素 e，把独立 Wyckoff orbit 按其内禀位点点群类型 H 聚合为计数 k(e,H)。H 使用标准的 32 类晶体点群，而非自造类别。k 计数独立 orbit 实例，不是展开后的原子数。

编码包含两层：

1. 元素级 inventory：非零 `(H, orbit_count)` 记录；
2. WP 残差：在同一 inventory 的合法 WP 计数候选中确定具体分配。

目前残差只是固定候选表内的可逆索引；不能把它当作通用、无词表上限的解码算法。连续坐标和晶格参数仍需后续几何模型。

在固定晶胞与标准设置下，G 与 H 的阶通过 orbit–stabilizer 关系确定重数；H 的固定向量子空间维数决定单个轨道代表的自由坐标数。全部 1731 个表列 WP 的检查通过。因此 inventory 可以确定每元素的展开原子数、orbit 数和代表坐标自由度总数。

同 G、H 仍可能对应多个 WP：它们的位置、取向、固定偏移等不能由 inventory 恢复，必须保留残差。上述自由度不包括晶格参数，也不保证生成坐标不碰撞、不落到更高对称性的特殊位置，或材料稳定。

## 本轮结果

| 检查 | 结果 |
|---|---:|
| 完整 WP 计数候选 | 32,368 |
| G、元素原子数上下文 | 1,050 |
| 非空位点点群 inventory 种类 | 3,165 |
| 单上下文最多 inventory | 120 |
| 位点点群 inventory 比重数 inventory 更细的上下文 | 457 |
| 同重数 inventory 对应不同坐标自由度的上下文 | 403 |
| inventory + 残差还原原始候选 | 32,368 / 32,368 |
| 原子数、轨道数、自由度预算一致性 | 全部通过 |
| 训练集元素记录 | 78,366 |
| 所在候选上下文被位点类型细分的训练记录 | 30,247，约 38.6% |
| 所在候选上下文中重数不足以确定自由度的训练记录 | 26,560，约 33.9% |

最后两行是**记录所在候选集合存在歧义**，并非真实材料标签本身有歧义，也不表示模型会在这些记录上出错。

例子：空间群 10、元素原子数 2 时，单个 `2i` orbit 的位点点群类型为 `2`，有 1 个自由坐标；单个 `2m` orbit 的类型为 `m`，有 2 个自由坐标。两者在重数 inventory 中相同，在位点点群 inventory 中不同。精确候选与 WP 编号见 `site_inventories/examples.json`。

训练集经验条件熵（给定 G、元素、元素原子数）为：完整 profile 0.5397 bit，重数 inventory 0.08235 bit，位点点群 inventory 0.17099 bit。这只是训练标签分布的描述，不能解释为验证集可预测性或神经模型收益。

## 有限创新边界

WyFormer 已经使用 element / site symmetry / enumeration；SymmCD 已经对逐 orbit 的位点对称性做扩散；Wren 已经使用 WP 多重集和共享特征。这里潜在的区别只能是**元素级计数 inventory 与 WP 分配残差的生成分解及去噪单位**。不能声称首次使用位点对称性、首次扩散或首次条件晶体生成。

阅读范围和逐篇结论见 `research/notes/site_point_group_inventory_prior_art.md`。未在所读论文中找到显式同款 inventory，并不等于全球新颖性已证明。

## 下一步模型门槛

先用既有开发验证集测试表示是否有可重复的帮助，再决定是否实现完整分阶段扩散。

- 条件均为给定 G 与 composition；最终用户条件尚未确定，此处仅是明确的可控试验任务。
- 对照必须保留完整 WP 信息和相同合法候选集，使用同样 backbone、参数预算、训练步数与遮盖样本。
- 比较位点类型聚合与逐 WP 的相同位点类型特征，避免把新增 H 特征收益误归为 inventory token 收益。重数聚合作为解释性对照。
- 隐藏目标时，不得输入真实 inventory、真实 orbit 数、真实自由度预算或目标长度。最终以完整 WP 预测质量计分，不能只报告更容易的粗层准确率。
- 开发结果需报告完整结构准确率、NLL、预算恢复、显存与时间；收益明确后固定协议，在预留 6,620 个验证结构上独立复核。既有官方 test 已用于前面实验，不能再称为未触碰测试集。
- 即使这一初筛通过，也只支持表示/去噪组件；完整条件扩散、连续几何有效性及稳定性仍需另外验证。

当前决策：值得进入小规模公平模型对照；尚不能选为最终 tokenizer。
