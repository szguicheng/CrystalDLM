# 无序 Wyckoff 集合合并：第二组开发诊断

## 编码

每个元素的 Wyckoff orbit 多重集由标准 WP 标识组成。仅在训练结构中统计无序代码对，依次合并最高加权频率的代码对；每个合并代码最多包含 4 个 orbit。保留全部 1,731 个基本 WP，允许未见模式逐 WP 回退。256 条合并规则不定义新的晶体学对象。

所有合并词均可展开为同一空间群中的 WP 多重集。输入 orbit 的排列不影响编码。当前只还原离散占位，未对原点变换或空间群 normalizer 进行取商，也不能还原几何。

完整训练集词表审计只用于覆盖/压缩分析。模型用的词表重新只在模型实际可用的 26,086 条训练结构上学习；不额外使用被 candidate cap 排除的训练结构。两套词表分开保存。

## 公平对照

三个变体：逐 orbit 基本词（unigram）、每个非零 WP 的重复计数词（rle）、训练集学习的无序合并词（setmerge）。它们面对完全相同的 32,368 个候选 profile、候选上限及数据筛选。

同一词内采用 WP 身份、重数、自由度与占据次数的组合嵌入，再经过相同的非线性 word projection，最后对 profile 内所有词求和。每个变体参数量均为 865,280，无独立的合并词可学习查找向量。候选分割方式是变体间的唯一结构差异。

该实验检验编码分组对候选学习的归纳偏置，**还不是直接在合并词上运行的离散扩散模型**。三者 Transformer 均每种元素一个输入槽位，不能从原始编码缩短推导 Transformer 加速。

- 统一 3 层、128 维 Transformer，batch 64，AdamW 3e-4，seed 17，2,000 步。
- 验证固定为按 material_id 哈希选择的 2,048 条；以平均 profile NLL 选择检查点。
- 三者使用相同的固定 WP 排他精确 MAP 解码。主比较为 setmerge 相对 rle 的带标签整结构匹配率；同时报告 NLL、无约束匹配率、耗时与显存。
- 配对结构 bootstrap 只反映这批验证样本的不确定性，不代替多训练种子。
- 测试结构可用于纯 codec roundtrip/覆盖检查，测试集模型性能仍不读取。
