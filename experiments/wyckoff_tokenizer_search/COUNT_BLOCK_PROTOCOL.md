# 基于 Wyckoff 占据次数的稀疏块编码

## 晶体学对象与明确差异

基础记录是同一元素的 `(Wyckoff位置, orbit占据次数)`。一个合并块是同 SG 下最多 3 个不同 WP 的计数记录集合。它表示这些位置的共同占据；不引入新的晶体学实体，不包含几何。

词表只用模型共同保留的 26,086 条训练结构拟合：从 RLE 记录开始，按无序代码对的训练频率依次合并，最多 256 条规则，最低支持数 20。保留每个基础计数记录作为回退。实际得到 182 条规则，因剩余频率不足 20 而停止。

旧集合合并先拆成 orbit 再学习，因此可能比 RLE 更长。新表示直接从 RLE 开始，每次合并减少一个单元；最大候选词数由 RLE 的 9 降到 6。本组仍固定 17 个槽位/元素，隔离预测表示差异，不把该长度变化直接当成 attention 加速。

## 无损与压缩证据

Slurm CPU 作业 532985：所有 32,368 个候选在编码—解码及反序检查下通过。新表示从不比 RLE 更长。共同 cap256 测试子集（8,730 个结构、26,261 个元素）编码单元 31,252 → 28,185，减少 9.814%；旧 orbit 合并在其中 828 个元素上比 RLE 更长。

这里的测试数字仅为表示统计，未评估测试模型性能；它不是全量预处理成功的 9,037 个测试结构。不要与旧词表在全测试集上的百分比直接相减。

## 模型对照

沿用 `DIRECT_WORD_PROTOCOL.md` 的直接词级去噪，候选空间、真实长度未知、模型容量、优化器、训练和验证结构固定。用独立数据包 `count_merge_candidates/data.pt` 同时重新运行 RLE 与 rlemerge，输出 `count_block_runs/`。不覆盖原始直接词级实验。

主比较是同样合法 MAP 读出后的带标签整结构匹配率；平均 profile NLL 用于选检查点。初始各 2,000 步、batch32、seed17，499,776 参数。只有明确正向信号才增加训练种子与后续生成验证。

通用的频率合并与结构片段词表算法已有先例。待验证的具体贡献是有 RLE 回退保证的 Wyckoff 稀疏占据块及其直接去噪用途；压缩检查不等于创新或模型效用已确认。
