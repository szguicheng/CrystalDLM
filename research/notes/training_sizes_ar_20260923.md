## What 6,000 means in this comparison

For the three principal MP/MP-20 generative runs, 6,000 examples is about **22.1%** of the 27,136-example CrystalFormer or WyFormer training set (about 4.5× fewer). Against Matra-Genoa-MP, it is roughly 5.2% of the paper's 115,663 pre-exclusion MP corpus / about 5.8% of an indicative 104k 90% training portion. Against the much larger Matra-Genoa-MPAS corpus it is about 0.22% of the reported combined corpus / 0.25% of an indicative 2.40M training portion. These comparisons are only scale comparisons: datasets, filtering, validation protocols, and model representations differ. For a three-paper “average,” the MP-20-only pair average is 27,136; including Matra-Genoa is misleading because its MPAS setting is a different million-scale corpus and its MP-only exact post-exclusion size is unreported.

## Interpretation cautions

- CrystalFormer and WyFormer both name 27,136 structures, but the papers' descriptions differ: CrystalFormer directly labels that number as its training dataset; WyFormer explicitly gives the total pool and 60/20/20 split, then independently corroborates the exact train count via “full MP-20 train.”
- Matra-Genoa's 115,663 and 2,668,720 are the paper's filtered corpus/model counts, while 10% of sequences are held out for validation. The exact MP-only post-space-group-1 count and exact realized random held-out counts are not stated. The MPAS arithmetic/count wording is internally ambiguous as noted above.
- Exclude generated samples (e.g., Matra-Genoa's 3 million generated structures), novelty/reference databases, and WyFormer's evaluation sample sizes from training-set comparisons.
- Fine-tuning counts for WyFormer's external GPT-4o-mini baseline are not disclosed. That separate experiment should not change the WyFormer base-run train count.

## WyFormer production checkpoint clarification (follow-up)

The paper's principal MP-20 generation benchmark remains **27,136 train structures**: §3.1.3 says it follows the original train/validation/test split, and Appendix L.1 calls 27,136 the “full MP-20 train.” The paper contains **no Alex-MP-20 / Alex-MP20 generative scaling experiment or sample count**. MPTS-52 is a separate generation dataset with no total count stated in the paper's dataset paragraph. AFLOW has 4,905 compounds, but it is used for property-prediction evaluation, not a larger generative-training run. Matbench Discovery is named as the source of a reference convex hull, not as an additional WyFormer training corpus.

The authors' public Hugging Face checkpoint `kazeevn/WyFormer-MP20` has `production_training: true` in its `config.yaml` (https://huggingface.co/kazeevn/WyFormer-MP20/blob/main/config.yaml, lines 223–231). The current author repository code documents production mode as merging dataset splits and its implementation concatenates train + validation + test when test data is loaded; the CLI also has `--no-test`, which means production mode can instead merge train + validation only (https://github.com/SymmetryAdvantage/WyckoffTransformer/blob/main/scripts/train.py, lines 22–23, 56–77; https://github.com/SymmetryAdvantage/WyckoffTransformer/blob/main/src/wyckoff_transformer/trainer.py, lines 1340–1398). Therefore the checkpoint is clearly marked production-trained, but the HF config alone does not establish whether that run also set `--no-test`; do not state 36,183 as certain from this config alone. If the test split was excluded, it is train+validation, approximately 36,183 (80% of 45,229, with exact split rounding); if test was loaded, it is the whole 45,229. This checkpoint distinction does not change the paper benchmark count of 27,136.

Official paper evidence: https://arxiv.org/html/2503.02407v4 — §3.1.1 gives 45,229 total and 60/20/20 split (lines 192–193); §3.1.3 says the MP-20 benchmark used the original splits (line 218); §2.2 distinguishes WyFormer MP-20 generation training from property prediction and reports AFLOW training at around 5k epochs (lines 164–169); Table 4/property-prediction discussion gives AFLOW 4,905 compounds (around line 264); Appendix L.1 says “Batch size: 27136 (full MP-20 train)” (lines 690–737). No `Alex-MP-20` match occurs in the v4 paper text.
