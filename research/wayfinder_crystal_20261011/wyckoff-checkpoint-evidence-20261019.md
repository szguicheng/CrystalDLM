# Wyckoff crystal model checkpoint evidence (2026-10-19)

Scope: official/first-party paper and repository artifacts for WyckoffDiff, WyFormer, and the DiffCSP++ geometry stage linked by WyFormer. No repositories were cloned and no model weights were downloaded.

| System | Generation target and paradigm | Training/backbone | Checkpoint evidence and availability |
|---|---|---|---|
| **WyckoffDiff** (ICML 2025) | Discrete D3PM over symmetry-native Wyckoff protostructure/occupancy descriptions; it does not directly predict full atomic coordinates or a CIF. | WyckoffGNN graph denoiser; paper evaluation/training uses WBM (257k substitution-generated structures based on Materials Project). The official code’s default is 3 GNN layers, hidden size 256, timestep max 1000. No named pretrained language-model backbone is indicated. | Official [repository](https://github.com/httk/wyckoffdiff) documents generator training (`train_d3pm`) and sampling from a user-supplied `--load` checkpoint. Its `evaluation_checkpoint/checkpoint.pth` is explicitly the pretrained **Wrenformer evaluator** required for Fréchet Wrenformer Distance, not the WyckoffDiff generator. The official repo tree has no `.pt/.pth/.ckpt` generator asset and the GitHub Releases API returned an empty list. Status: **public code/data, generator weights not found in official release assets; a downloadable pretrained WyckoffDiff generator checkpoint is unverified**. |
| **WyFormer** (ICML 2025) | Permutation-invariant **autoregressive** Transformer that emits discrete Wyckoff representations (space group plus element/site-symmetry/enumeration fields); a representation, not full coordinates. | Crystal-domain training on structures; the official HF Alex-MP20 config names `dataset: alex_mp_20`, uses 3 Transformer encoder layers and 4 attention heads, with no learned positional encoding (`learned_positional_encoding_max_size: 0`). The paper also evaluates pretrained language models as baselines; that does not make the released WyFormer checkpoint an LLM-initialized model. | Official [HF collection](https://huggingface.co/collections/SymmetryAdvantage/wyformer) lists [SymmetryAdvantage/WyFormer-Alex-MP20](https://huggingface.co/SymmetryAdvantage/WyFormer-Alex-MP20/tree/main) and [kazeevn/WyFormer-MP20](https://huggingface.co/kazeevn/WyFormer-MP20/tree/main). Hugging Face metadata exposes `best_model_params.pt` (573,719 bytes for the official Alex-MP20 repo), `config.yaml`, and processor metadata: **public trained crystal-model checkpoints are available**. This is a WyFormer AR checkpoint, not a diffusion checkpoint. |
| **WyFormer → modified DiffCSP++** | Two-stage path: WyFormer generates a Wyckoff gene; DiffCSP++ separately diffuses full fractional coordinates/lattice to restore a 3D structure. Do not attribute DiffCSP++’s coordinate diffusion to WyFormer. | The WyFormer README links to [`kazeevn/DiffCSPNew`](https://github.com/kazeevn/DiffCSPNew) for the modified geometry code. That URL currently resolves to [`kazeevn/GeoCSP`](https://github.com/kazeevn/GeoCSP), whose README exposes the standard CSPNet inference checkpoint at `data/mp-20/test_ckpt.pt` and describes it as a 6-layer GNN denoiser. The file is present in the public Git tree (49,170,207 bytes); direct path: [test_ckpt.pt](https://github.com/kazeevn/GeoCSP/blob/master/data/mp-20/test_ckpt.pt). | Status: **a public MP-20 DiffCSP++ checkpoint is exposed by the currently linked fork**. Its file presence and size were checked from Git metadata only (not downloaded). I could not verify that this particular current `test_ckpt.pt` is byte-for-byte or procedurally the exact checkpoint used in the ICML WyFormer paper’s modified DiffCSP++ experiment; treat that historical equivalence as **unverified**. It is the geometry-stage checkpoint, not a pretrained WyFormer or an LLM backbone. |
