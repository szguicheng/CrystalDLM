# 批量英文描述标注前核查

日期：2026-10-12。范围：待标注数据量、字段/提示词、API 请求设置与批处理准备；本轮没有新增 API 调用或启动全量标注。

## 数量与实际文件核查

按每个材料一条英文描述，全量待标注池为 **45,629 个材料**：train 36,491、val 4,517、test 4,621。三个划分都可制作描述，训练只读取 train。

本轮逐条扫描总表及三个划分文件：材料 ID 和现有结构键各有 45,629 个唯一值；划分文件 ID 集合与总表一致，未发现重复 ID 或错分。检查 ehull 有限值/范围/单位、原子数、元素种类数和全占位均通过。四个压缩数据文件的 SHA-256 与 manifest 一致。详见 [机器核查结果](preannotation-data-audit.json)。结构键检查不覆盖不同晶胞表达下的等价结构。

ehull 标签为原始连续 MP 标签，单位 eV/atom，实际范围 0–0.299992528703707；抽样分箱为 0、(0,0.05]、(0.05,0.1]、(0.1,0.2] 各 10,000 个，(0.2,0.3] 为 5,629 个。不将分箱替代连续标签。

已有 3 个训练材料的 PLaID 编解码/基础字段样例；两次成功 API 响应只覆盖同一个材料 mp-624928。这些是接口与事实核查样例，尚未计入冻结后的正式标注成果；正式全量队列仍按 45,629 个规划。最终可用数量要由全量 PLaID 处理的成功记录确定。

## 已核对的设置

- API：SciencePal `/v1/chat/completions`，模型 `deepseek-v4-pro`，`thinking={"type":"enabled"}`，`reasoning_effort="max"`，流式返回，输出上限 `max_tokens=16384`。用户接受标准 max 请求设置；无思考统计不再作为推进阻碍。另一个 Responses 路径失败，不采用该路径。
- 密钥：引用现有 `.env` 中的 `SCIENCEPAL_API_KEY`，不写入描述、提示词或研究配置产物。
- 英文提示词：3–5 句，只改写提供事实；缺失字段省略。当前两个成功段落均为 4 句，组成、空间群、原子/轨道数、晶格、体积及密度与输入一致。
- 结构版本：文字针对 PLaID 解码结构提取事实；原始 MP ehull 单独保存，若文字提及就标明原始来源，不称为解码结构重算结果。
- 项目分工：离线 LLM 制作英文监督文字；PLaID 承载晶体结构；后续共享网络以 AR 处理文字、diffusion 处理晶体；GRACE-3L-OAM-L 是后续外部评价器。本轮不重算标签，不恢复已搁置的新 tokenizer 训练。

## 全量前需要补齐

1. **全量 PLaID 编解码和字段提取。** 45,629 是源数据数量，不是已完成的结构 token/描述事实数量。应先形成成功记录与失败记录，再冻结真实待标注队列。
2. **局部结构信息。** 配位数、近邻、多面体、角/边/面共享和连接维度尚未提取，当前三个样例的该输入为空。固定分析方法、参数和结构版本后再填入；不能由 LLM 猜出这些字段。若只用当前输入，输出主要是组成、对称和晶胞摘要。
3. **小批次质量与运行验证。** 当前只有一个材料的 API 质量证据。建议从训练集选 30 个覆盖不同元素/对称/ehull 区间的材料试标，再检查描述与事实是否一致、缺失局部信息的处理、长度与费用。批量调用还需要最小的材料 ID 对应、已完成记录续跑和限速设置；目前未核查吞吐及费用。

训练样本段落顺序、目标条件接口、生成晶体的 GRACE/ehull 评价与 48 GPU 小时预算仍在决策地图中；它们不影响本次数量结论，但尚不能据此启动完整训练。

建议顺序：结构预处理与局部字段 → 30 个训练材料试标 → 核对质量及成本 → 全量标注。
