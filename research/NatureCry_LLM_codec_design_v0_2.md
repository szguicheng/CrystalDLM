# NatureCry v0.2：LLM 空间描述与语义重建设计

创建日期：2026-10-01；更新日期：2026-10-02。状态：**初步验证完成**。已完成两个案例试点和冻结 100-case 主实验，首次严格恢复 84/100，其中 3 个连接失败另列。范围仅为自然语言编解码；NatureCry 的训练与学习收益验证留待后续讨论。

阶段结论：LLM 自然语言表示、盲解码和验证筛选的路线已通过初步可行性验证。后续可保留通过检查的描述—晶体配对，丢弃失败配对，不要求所有输入都成功。该结论不等同于训练收益、全域可靠性或任意语言解码已经得到验证。按用户要求，本阶段结束，后续训练另行决定。

## 1. 用户要求与对上一轮的纠正

用户需要 LLM 生成自然、具有空间含义的晶体描述，再从描述恢复结构。上一轮“结构字段→固定英文模板→正则解析”的实现偏离了这个目标。

上一轮 100/100 是固定格式程序编解码的工程基线；它确认保真所需信息和几何后端可用，不能视为 LLM 自然描述的恢复结果。旧代码、样本和结果保留，作为新方法的对照。

本版固定信息完整性与验证标准，允许模型选择描述顺序、措辞、空间参照和关系表达。
生成的正文应描述位置、相对关系、重复与对称操作，保留重建所需数值。输出不通过嵌入原 CIF、JSON、隐写 token、材料 ID 或未提供给读者的 sidecar 来实现恢复。

## 2. 其他领域的可借鉴工作

### Natural Language Autoencoders：最接近的总体逻辑

来源：[Natural Language Autoencoders Produce Unsupervised Explanations of LLM Activations](https://transformer-circuits.pub/2026/nla/index.html)，Anthropic / Transformer Circuits，2026-05-07；[配套代码](https://github.com/kitft/natural_language_autoencoders)。

原文采用两个学习模块：activation verbalizer 将激活变成自然语言，activation reconstructor 从文字恢复激活；二者围绕重建误差训练。
作者还通过保持语义的改写、重排等干预测量重建变化，检验模型是否利用表面上不可读的编码。

借鉴：把“晶体→自然描述→晶体”作为可测量的往返目标，并检查文字是否具有可读、稳定的含义。
边界：原研究重建激活向量，使用近似重建指标；它没有证明可逐数值无损地恢复晶体，也没有单靠重建损失保证每条解释都正确。

### Text2CAD：几何描述和可执行重建

来源：[Text2CAD, NeurIPS 2024 正式论文](https://proceedings.neurips.cc/paper_files/paper/2024/hash/0e5b96f97c1813bb75f6c28532c2ecc7-Abstract-Conference.html)；[方法全文](https://arxiv.org/html/2409.17106v1)；[官方代码](https://github.com/SadilKhan/Text2CAD)。注意这是 arXiv 2409.17106，不是另一篇同名 Text2CAD。

其数据标注流程把 CAD 形状信息与设计参数交给 VLM/LLM，生成不同详细程度的自然语言设计说明，再训练模型从文本产生参数化 CAD 构造序列。
描述可以表达同心、共面、法向拉伸、相对尺寸等几何关系，而不是逐字段加英文前缀。

借鉴：先提供可靠几何事实，再让 LLM 组织自然描述；重建时从语义生成可执行的构造表示。
边界：其输出采用量化的 CAD 序列，评价包含几何与参数准确性，并非任意自然文本严格恢复全部原始 CAD 数据。低详细程度描述不一定唯一确定几何。

### NL2TL：把自然语言关系落到形式语义

来源：[NL2TL, EMNLP 2023](https://aclanthology.org/2023.emnlp-main.985/)；[官方代码](https://github.com/yongchao98/NL2TL)。

该工作使用 LLM 与人工标注构造自然语言/时序逻辑配对数据，再训练语言模型转换自然语言。它将通用逻辑结构与具体原子命题分开，以促进跨领域泛化。

借鉴：分清“关系是什么”与“关系作用于哪个元素、轨道或坐标”；使用形式约束落地语言含义。
边界：时序逻辑表达系统要求，通常不是高精度连续几何的完整编码。迁移到晶体的效果待验证。

以上是方法类比，不是 NatureCry 可行性的直接实验结果，也不是全领域创新性认证。本轮核对了 Text2CAD 的数据标注、模型与限制章节，NLA 的方法与语义干预章节，以及 NL2TL 的正式论文摘要与项目信息。

## 3. 建议的最小架构

```text
原始晶体 C
    ↓
晶体学工具提取可核对事实 F(C)
    ↓
LLM verbalizer：自由组织空间描述 T
    ↓                         只传递 T
LLM semantic decoder：解析结构约束/构造计划 P(T)
    ↓
固定几何内核执行约束和对称操作
    ↓
恢复晶体 Ĉ，并与 C 比较
```

工具提供事实而不生成英文模板。事实可以包含晶格、标准与原始坐标参照、轨道、等价关系、自由参数，以及经过计算证实的平面/对称/重复关系。
几何内核负责数值计算、周期性、对称展开和约束一致性；两个 LLM 分别承担空间描述和语言语义解析。

第一版建议采用这样的模块组合，而不是马上联合训练。可分别诊断 encoder 遗漏了什么、decoder 误解了什么，以及几何执行是否正确。

## 4. Verbalizer 的要求

给模型原始结构和可信事实包，要求它像给另一位研究者说明如何重建结构一样写正文。句式与段落顺序自由。

描述应体现：

- 单位胞的形状、尺寸、基矢与坐标参照。
- 元素如何占据空间；哪些位点独立，哪些由对称或周期重复生成。
- 镜像、平移、反演、共享坐标等已经证实的关系。
- 重建所需位置参数、占据率和数值精度。

允许在正常科学叙述中使用数字、坐标或方程。自然描述不意味着省略决定几何的数值。
不能用“层状”“密集”“八面体配位”等未经验证的判断补充信息；原子位点共面不自动意味着化学意义上的二维层状材料。

例如，Tb₈Mg₄ 的描述可以从“原子位点位于两个与 ac 平面平行的平面上”出发，解释平面间距、面内位置及对称关系，再给出精确定位依据。这是描述策略，不是本轮已运行的 LLM 编码结果。

## 5. Semantic decoder 的要求

decoder 只看到自然语言正文与公共晶体学定义，不看到原 CIF、原事实包、原编码 JSON、源材料 ID 或 encoder 的聊天上下文。
第一轮可以使用同一个基础模型的两个隔离会话；同模型不代表已经独立证明语义泛化，后续增加跨模型重建对照。

decoder 输出有限、可验证的结构约束或构造计划，支持数值、参照对象、相对关系和对称操作。其内部形式可以是结构化数据；对外的 NatureCry 编码仍是 LLM 生成的自然描述。
几何内核执行计划并输出结构。语言中缺少必要信息或约束互相矛盾时，记录“欠确定/冲突”，不自动猜一个看起来合理的结构并判为恢复成功。

不能用简单正则匹配正文句式代替这个语义 decoder。也不在第一版执行模型生成的任意 Python 代码；采用有限结构计划可区分语言解析与数值执行错误。

## 6. 如何判断描述真正具有语义

主实验的硬要求是原始结构恢复：自然语言 decode 后的晶体必须与原始输入晶体匹配。主指标为恢复成功率与几何误差，不能用语义评分、描述自然度或关系编辑成功代替。用户于 2026-10-02 明确了这个优先级。

下面的等义改写、关系修改与消融属于 tokenizer/表示性能的独立辅助实验，不作为主实验恢复成功的替代条件；首轮主实验不执行这些辅助项。

第二项检验含义不变的改写：由另一会话或人工改写段落和措辞，保留定位信息、数字、单位和关系，再让 decoder 重建。验证改写本身没有改变含义，避免把删去必要信息的摘要当作等义改写。

第三项做含义改变的干预：修改一个可验证的几何关系，检查恢复结构的变化是否对应预期。例如改变 b 边长时，相关以 b 为参照的距离应随之变化；保持其他条件不变修改一个轨道自由参数时，变化应传播到该轨道。

第四项消融关系信息：移除指定空间关系或参数，检验 decoder 是否识别欠确定性，或者重建误差是否暴露该信息的贡献。

另外检查文本是否退化为逐原子坐标表、固定模板、不可读 token 或无意义数字编码。不能通过将原始结构全文拷贝到“补充内容”绕过自然语言瓶颈。

这些检查借鉴 NLA 的语义干预思路；晶体的恢复标准需按几何与对称等价另行制定。

## 7. 本块实验如何起步

先用已讨论的两个例子检查描述能否同时自然和信息完整，再沿用原先冻结的 100 个 case 进行比较。原固定模板作为程序基线保留。

候选对照：

| 路径 | 目的 |
|---|---|
| 固定模板＋规则解析 | 已验证的格式与几何基线 |
| LLM 空间描述＋LLM 语义解析 | 目标方案 |
| 目标方案的等义改写＋LLM 语义解析 | 测语义稳定性 |

主结果报告首次生成、首次解码的成功率与误差。若提供纠错/补写机会，单独报告修复后的结果、次数、成本，保留每次原始文本与输出。
检查器可以读取原结构评估误差；不能把原始坐标直接提供给 decoder 再将其计为盲重建。

沿用原结构保真标准作为主要严格指标。若另测理想化结构或较宽松误差，应单列目标、容差与结果，不将目标转换后的恢复当成原始输入的精确恢复。
原 100-case 基线中有 17 个样本需要精度修正；本版要公开检验 LLM 如何在自然叙述中保留这些偏差信息，不能默默抛弃。

结果区分：描述遗漏/错误、描述歧义、语义解析错误、几何执行错误，以及模型/API 失败。保留全部冻结样本，不用成功样本替换失败样本。
