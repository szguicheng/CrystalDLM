# Tokenizer 方法选择与交付核对

用户目标：找到一个对做模型有作用、且有一定创新的tokenizer方式，并可使用Burgundy验证。

本轮选出的方式为“空间群边轨道 tokenizer”。它基于已有位点稳定子、Wyckoff位置族、空间群操作与周期连接概念；增量限定为边轨道记录粒度及离散prototype/连续几何分离接口。

| 要求 | 当前证据 |
|---|---|
| 基于晶体学基础概念，而非新增物理对象 | 方案说明给出每个字段含义；公式P/b来自仿射位点稳定子；原文/官方代码核查区分已有ASU与新边合并 |
| 是具体可执行的表示方式 | 核心编解码代码、独立prototype与geometry文件、真实KrF₂例子；CPU作业535457运行核心例子成功 |
| prototype与几何有明确分工 | 512个结构的整数prototype、原几何往返、每个三套独立自由参数的抽象周期图检查均通过 |
| 对模型有实际作用 | 与同网络ASU逐邻居对照输出/梯度一致，512图时省44.6%峰值分配内存、耗时增加11.7%；权衡已明确 |
| 与条件、非AR方向相容且有模型验证 | 以离散prototype＋指定晶格为条件，全部位点并行的单级去噪已训练；冻结模型在5343个独立保留结构上MSE较identity下降71.16% |
| 对新增之处不过度宣称 | coGN已含ASU和仿射边；官方构图逐条保留邻居，本实现进一步合并边轨道。未声称新晶体学概念、首次扩散、全球首创或比ASU更准确 |
| 表格与PPT可审阅 | 第11页原生可编辑表格与备注更新；原报告其他包内容字节保持；新版渲染检查与最终包验证通过 |
| 结果可追溯 | 所有阶段结果、失败、源码摘要、冻结模型摘要与独立复核记录保留；核心包有逐文件SHA-256清单 |
