# MP ehull 0–0.3：首轮选择结果

来源：用户提供的 MongoDB `groupdb.mp_api_all_2025_7`，记录标注的 MP 版本为 `2025.06.09`。只读下载 154,879 条元数据，64,043 条通过 ehull、原子数、元素数和有序完整占位筛选。采用原始材料记录中的 `structure` 与 `energy_above_hull`，未重新计算标签或使用预测字段替换。

最终选择 45,629 条，88 种元素、178 个空间群。原子数 1–20，元素数 1–4，ehull 0–0.3 eV/atom。五区间按化学体系候选数平方根分配配额，再按 seed 17 的 material_id 哈希无放回选择；最后一层不足配额不补采。

训练/验证/测试：36,491 / 4,517 / 4,621，按固定结构哈希约 80/10/10 划分。

- `records.jsonl.gz`：全部入选的原始结构与标签，包括划分、组成和来源信息。
- `train.jsonl.gz`、`val.jsonl.gz`、`test.jsonl.gz`：对应划分。
- `selection.csv`：材料 ID、标签、化学体系、结构键与划分。
- `manifest.json`：过滤、来源、抽样、数量与文件哈希。
- `sampling_report.json`、`split_report.json`：逐区间/体系配额与划分规则。
- `verification.json`：全部 45,629 条的范围、有序占位、来源值精确保持和文件完整性检查。

精确重复检查仅覆盖同一晶胞下的坐标整体平移与位点排列（8 位小数），共删除 1 条重复记录；未进行跨晶胞/对称等价的全局去重。原始存档不显式标注 ehull thermo_type，保留原始来源信息；三条官方 API 标签对照作为来源佐证，不等于全库计算溯源。

没有训练、PLaID 编码、生成晶体评价、DFT/MLIP 弛豫或标签重算。数据库写命令为零：未插入、更新、删除、创建索引或修改配置。
