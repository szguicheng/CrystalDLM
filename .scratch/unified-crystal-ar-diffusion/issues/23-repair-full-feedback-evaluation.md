# 修正模型的 700 组循环生成与 ehull 评价

Status: done
Created: 2026-10-22
Labels: experiment, evaluation

用户要求把已训练的结构修正模型用于原七空间群、每空间群100组循环生成，并跑完整流程含ehull。沿用最多3次、结构有效且符合目标空间群即停止；GRACE只在生成后评分。

两组策略使用相同新模型：直接重新生成、根据检查反馈修改。每组共享首轮，后续种子配对。每策略700组，各组只选择首个结构成功输出；无成功保留终轮失败，均计入分母。不根据ehull挑选或增加重试。

先运行独立7组流程检查，再启动三卡700组正式生成；自动导出最终候选、运行GRACE弛豫与固定凸包评分、去重及训练集新颖性比较，汇总80meV达标和弛豫后空间群保持情况。

当前：9项合约测试通过，三卡7组smoke及两臂GRACE完整评分完成，exit0；10次反馈重试均进入晶体段。正式700组已在LiuGangGPU的tmux `repair-loop-full-20261022` 启动，物理GPU1/2/3，随后自动两卡GRACE评分和汇总。执行状态见实验目录 `formal-stage.txt`、`logs/` 及 `run_001` 回执。
